## 画面ごとの操作項目と確認観点

### D-01 プロジェクト
- 操作: セクション折りたたみ、チェックで完了、行ホバーで 4 アイコン (編集 / 日付 / コメント / その他)、末尾「タスクを追加」、完了表示トグル
- 確認観点: 長文タイトル行 (60 文字) の折り返しで操作アイコンの位置が崩れないか。サイドバーの件数表示が邪魔でないか
- 確認観点: サイドバー最下部の同期状態 (サイドバーのある全デスクトップ画面共通。4 状態は D-09d) が目に入りすぎず、見落とされもしないか

### D-01b サブタスク展開 / D-01c サブタスク追加フォーム
- 操作: 親行の左余白のシェブロンで展開・折りたたみ、子行のチェックで完了、孫の展開 (子のシェブロン)、末尾「サブタスクを追加」でインライン追加フォーム (D-01c) を開く。フォームは期限 / 優先度 / リマインダー / ラベルのツールバーと「キャンセル」/「サブタスクを追加」ボタンを持つ
- 確認観点: 1 階層 32px のインデントで階層が読めるか (孫は 64px)。フォームが行の流れを壊さないか (行の位置に差し込まれ、前後の行がずれるだけか)
- 確認観点: 件数バッジ (1/3) の位置がメタ行の末尾で邪魔にならないか。シェブロンを左余白に出したことで、シェブロンなしの行とチェックボックスの位置が揃っているか
- 確認観点: 完了した子行は D-03 と同じ「グレー文字 + 緑の塗りつぶしチェック」で表現している

### D-02 クイック追加
- 操作: 入力中に `明日` `p1` `#買い物` `@食品` がチップ化。ツールバーで補完。プロジェクト選択は左下
- 確認観点: チップ化が入力の邪魔にならないか。Enter で追加、Shift+Enter で説明に移る想定

### D-03 タスク詳細
- 操作: タイトル / 説明の直接編集、各プロパティ行をクリックでポップオーバー、サブタスクの追加と完了、コメント投稿
- 操作: 親タスクのパンくず (サブタスクを開いたとき) は未描画
- 確認観点: パネル幅 400 で情報量が多すぎないか。プロパティの順序 (プロジェクト → 期限 → 優先度 → ラベル → リマインダー → 繰り返し)
- 確認観点: 完了したサブタスクは取り消し線ではなく「グレー文字 + 緑の塗りつぶしチェック」で表現している (pen の制約)。これで完了済みと伝わるか

### D-04 今日
- 操作: 期限切れグループの一括再スケジュール、各行の完了
- 確認観点: 期限切れなしのとき (D-04 今日 (期限切れなし)) の見出し省略が自然か

### D-05 近日
- 操作: 週ストリップで日付移動、月セレクタ、各日の追加
- 確認観点: 予定なしの日 (10/15) に「タスクを追加」だけ出る表示でよいか

### D-06 フィルターとラベル / D-06b ラベル詳細
- 操作: フィルター / ラベルの追加、件数表示、ラベル詳細へ
- 確認観点: Phase 5 のフィルターをここに同居させてよいか

### D-07 日付ピッカー / D-07b 繰り返し設定
- 操作: 自然言語入力、クイック選択、カレンダー、時刻、繰り返しプリセット、RRULE プレビュー
- 確認観点: RRULE 文字列の表示がノイズか (非表示にする選択肢あり)

### D-08 リマインダー / D-08b OS 通知
- 操作: 期限から / 日時指定の切替、候補の追加、追加済みの削除
- 確認観点: 通知の「完了」「後で」ボタンで足りるか

### D-09 設定 (未ログイン) / D-09c 設定 (接続済み) / D-09b 競合バナー / D-09d 同期状態一覧
- 操作 (D-09 未ログイン): 説明文を読み、「Google でログイン」を押す (ブラウザが開く)
- 操作 (D-09c 接続済み): ログイン中のアカウント表示、ログアウト、今すぐ同期、Drive フォルダ変更
- 確認観点: クライアント ID の入力欄を廃止し、ログインボタンだけにしたことの妥当性。未接続時の説明文で何が同期されるか伝わるか
- 確認観点: 未ログイン時は同期の操作行を出さない (D-09) 構成で迷わないか。競合バナーの文言が分かるか
- 確認観点 (D-09d): 同期中 / 同期済み / オフライン / エラーの 4 状態が見分けやすいか。サイドバー最下部という位置と、エラー時のクリックで再同期する想定が自然か
- 確認観点: 外観 / 日付と時刻 / アカウント のペインは未描画。項目は M-07 を参照

### D-10 ボード
- 操作: カードのドラッグ、列追加
- 確認観点: ドラッグ中のカード (影と傾き) とドロップ位置 (赤い線) を 1 枚で表現
- 確認観点: カードの情報量 (タイトル + 期限 + 優先度) で足りるか
- 確認観点: 「完了」列は通常のセクションとして扱う (完了タスクの既定非表示とは別)。
- 確認観点: 「セクションを追加」列は幅 200 (他の列は 280)。1440 幅に収めるための寸法で、実装時は横スクロール前提で揃える

### D-11 状態 (D-11a 空のプロジェクト / D-11b 読み込みエラー / D-11c 要修正行)
- 確認観点: エラー文言が次の行動 (再試行 / 場所を開く / Excel で開く) を示しているか

### D-12 初回起動 / D-12b Google 接続 / D-12c 受信トレイ
- 操作: 保存先の選択 (D-12) → 「Google でログイン」ボタンのみ (クライアント ID の入力は廃止)、またはスキップ (D-12b) → 受信トレイ作成 (D-12c)
- 確認観点: 3 ステップで迷わないか。スキップは省略できる D-12b にだけ置く

### D-13 最小ウィンドウ 960x600
- 確認観点: サイドバーをアイコンだけにしたとき、プロジェクト一覧へどう行くか (アイコン「一覧」で展開)
- 確認観点: 同期状態はレール最下部のアイコンだけになる。状態が色とアイコンで伝わるか

### ダーク (D-01 / D-03 / D-04)
- 確認観点: ライトと同じ情報量・同じ配置のまま、コントラストと優先度色が読み取れるか

### モバイル M-01〜M-07
- M-01 操作: ハンバーガー / FAB / 行タップ / 右スワイプ完了 / 左スワイプ日付 (Phase 6) / 長押し選択 (未描画)
- M-01b 操作: 親行の件数バッジ (シェブロンを含む。展開中は「1/3 ˅」) をタップして展開・折りたたみ。子行は 24px インデント。末尾「サブタスクを追加」で M-02。洗剤の行は折りたたみ状態の例 (「0/2 ›」)
- ヘッダ右の同期アイコン (M-01 / M-07): 同期中のみ回転アイコン (M-01 の例)、同期済みは非表示、オフライン / エラーはアイコンを表示 (M-07 の cloud-off が例)。M-04 / M-05 には未配置
- M-06 ドロワー最下部に同期状態 (デスクトップと同じ 4 状態の表示)
- M-02 操作: トークン入力 / ツールバー / 送信
- M-03 操作: 各行タップでシート / サブタスク追加 / コメント
- M-04 操作: 再スケジュール / 完了
- M-05 操作: 週ストリップ横スクロール / 日付グループ
- M-06 操作: 項目タップで遷移 / 設定
- M-07 操作: 各行タップ
- 確認観点: 下部タブ 4 つ (今日 / 近日 / 検索 / 一覧) で足りるか。FAB の位置がタブと干渉しないか。スワイプの左右割り当て (右 = 完了、左 = 日付)。クイック追加シートがキーボード上に収まるか
- 確認観点 (M-01b): 件数バッジがタップ領域として十分な大きさか (行全体のタップは M-03 を開くので、バッジとの押し分けが分かるか)。24px インデントで階層が読めるか
- 確認観点 (同期表示): ヘッダ右のアイコンが「その他」ボタンと近すぎないか。同期済みで非表示にして問題ないか
- 確認観点: タスク行の高さは 40 (日付付きは 61) で、タップ領域の目安 44pt を下回っている。実装時に拡大予定
