# Todoist の iPhone 版と PowerToDo の差 (2026-11-28)

`~/Downloads/Todoist動画` の画面録画 3 本 (日本語の Todoist、新しいアカウント) と、`~/Downloads/powertodo_ios_todoist` の画面写真 14 枚 (使い込んだアカウント) を、2 秒ごとのコマにして見た。PowerToDo の iPhone 版 (2026-11-28 の main) と比べた差を、画面ごとに書く。「差」の列は、Todoist にあって PowerToDo に無いもの、または作りが違うもの。

## 1. タスクの詳細 (下からのポップアップ)

| Todoist | PowerToDo | 差 |
|---|---|---|
| 上に丸い「×」と「…」(右)。「…」にタスクの操作がある | 「×」だけ。削除は下の文字ボタン | 「…」メニューを足す |
| タイトル (チェックの丸つき) の下に、プロジェクトの行 (`# 名前`) と日付の行 (緑のカレンダーの印) だけ | プロパティ 6 行 (プロジェクト、期限、優先度、ラベル、リマインダー、繰り返し) を、空でも常に並べる | 値のあるものだけ行にし、空のものは「チップ」に回す |
| 横にスクロールするチップの列: 説明、優先度、リマインダー、ラベル。押すと、その項目が行として足される | 無い | チップの列を足す |
| 「サブタスク」の見出しに、たたむ矢印と「+」。サブタスクは丸いカードの中。「サブタスクを追加」は枠つきの行 | 見出しと件数 (n/m)、行、追加の行。たためない | たたむ、カード、「+」 |
| 「コメント n」に最新の 1 件と「すべて表示」。下にクリップつきのコメント欄 | 同じ作り | 差は小さい |
| タイトルを押すと「タスクを編集」(×、タイトル、✓。説明の欄つき) | タイトルを押すと名前のシート | ✓ で確定する形、説明の欄を同じ画面に |

| Todoist | PowerToDo | 差 |

## 範囲外にするもの

担当者 (共有)、チーム、テンプレート、ワークスペース、有料の機能 (期限、位置情報、所要時間、カレンダーのレイアウト)、音声入力、メール送信、アクティビティ。

## 作る順の案

1. 「表示」のシートを Todoist の形にして、プロジェクトとインボックスにも出す (§3)。デスクトップに無い「スマート」「期限のフィルター」は、デスクトップの「表示」と同じ設定の行に足す。
2. 日付のシートを Todoist の形に (§2): ✓ で確定、入力欄、縦に続くカレンダー、「時間」と「繰り返し」の行。
3. タスクの詳細を Todoist の形に (§1): 「…」メニュー、チップの列、サブタスクのたたみ。
4. 行の長押しメニュー、プロジェクトの「…」、セクションの見出し (§5)。
5. 近日予定の月のカレンダー (§4)、閲覧の整理 (§7)、クイック追加の候補 (§6)。
