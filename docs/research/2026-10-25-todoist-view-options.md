# Todoist デスクトップ版の「表示」メニュー (調査メモ)

調べた日: 2026-10-25
対象: Todoist デスクトップ版 9.32.0 (macOS, Apple シリコン)、所有者のアカウント
方法:
- 受信トレイで上の帯の「表示」を押し、メニューと各選択の中身を写真に撮った
- 選んだ値は変えずに Esc で閉じた
- 所有者のプロジェクトの表示の設定は変えていない

## 1. メニュー (受信トレイ)

上の帯の右の「表示」を押すと、ボタンの下に幅約 260 のメニューが出る。上から:

- レイアウト (右に「?」)
  - 3 つの大きなボタン: リスト / ボード / カレンダー
  - カレンダーには有料プランの印
- 完了したタスク: 切り替え (既定は切)
- 並び替え (たためる見出し):
  - グループ: なし / 日付 / 追加日 / 期限 / 優先度 / ラベル
  - 並び替え: 手動 / 名前 / 日付 / 追加日 / 期限 / 優先度
- フィルター (たためる見出し):
  - 日付: すべて / 今日 / 今週 / 次の 7 日間 / 今月 / 次の 30 日間 / 日付なし
  - 作成日: すべて / …
  - 優先度: すべて / …

各選択は右寄せの枠 (幅約 140) で、押すと下に選択肢の一覧が出る。今の値に「✓」が付く。

## 2. PowerToDo に無いもの

- 「期限」(Todoist の Deadline): PowerToDo のデータに無い
- 担当者での並び替え: このアカウントの受信トレイのメニューには出ていなかった
