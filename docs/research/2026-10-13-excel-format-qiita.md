# 調査: Qiita「エクセル七つ道具ではじめるシンプルなタスク管理」の形式

出典: https://qiita.com/y-tetsu/items/c028737330fc47106fe8 (2024-07-21 投稿、2024-07-28 更新)
調査日: 2026-10-13

## 構成

ブック内のシートは 2 枚。

### シート「タスク一覧」

1 行目が見出し、2 行目以降がタスク。列は以下。

| 列 | 用途 |
| --- | --- |
| No. | タスクの識別番号 |
| プロジェクト | 大項目。設定シートのリストから選択 |
| カテゴリ | 中項目。設定シートのリストから選択 |
| タスク | タスク内容 |
| 担当 | 実施者。設定シートのリストから選択 |
| 優先度 | 高 / 中 / 低。設定シートのリストから選択 |
| 進捗 | 0〜100 の割合。100 で完了扱い |
| 開始 | 着手日 (予定兼実績) |
| 終了 | 納期 (予定兼実績) |
| 日数 | 開始〜終了の営業日数。土日と設定シートの祝日を除く |
| 備考 | メモ |

### シート「設定」

- 1 行目: 見出し行 / 開始行 / 開始列 / 終了列 (タスク一覧表の位置をマクロが参照する)
- 並び替え優先項目: ソート時に優先する見出し名を上から順に列挙
- プロジェクト / カテゴリ / 担当 / 優先度 / 祝日 のリスト。各 30 行分の枠
- プルダウンの元の値は `=OFFSET(設定!$G$4,,,COUNTA(設定!$G$4:$G$33)+1)` のように可変長にしている

## 使っている Excel 機能 (七つ道具)

1. テーブル書式 (見出し固定、縞模様)
2. データの入力規則 (リスト入力)
3. 条件付き書式 (進捗 100 で行をグレー、終了が今日より前かつ未完了で警告色)
4. フィルター
5. 関数 (NETWORKDAYS 系で日数算出)
6. マクロ (VBA): ソートボタン、行追加ボタン
7. ウィンドウ枠の固定

## PowerToDo での扱い

- 10 列と 2 シート構成はそのまま採用し、末尾に拡張列を足す (詳細は全体設計 spec §1)
- VBA マクロは採用しない。ソート・行追加・完了表示はアプリ側で行う (.xlsx、マクロなし)
- 条件付き書式はアプリが xlsx 生成時に付与する
- 日数は Excel 式ではなくアプリが計算した値を書く (LibreOffice や Google スプレッドシートで開いたときの互換性を優先)
- 祝日はプロジェクトごとではなく共通ファイル `_PowerToDo.xlsx` に置く
