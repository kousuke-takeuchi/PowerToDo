# Todoist デスクトップ版の見た目と動き (調査メモ)

調べた日: 2026-10-25
対象: Todoist デスクトップ版 9.32.0 (macOS, Apple シリコン)、所有者のアカウント
方法:
- 画面の写真: `screencapture`
- ウィンドウの大きさの変更とマウス操作: Accessibility API と CGEvent を使う小さな Swift のツール
- 動画: `ffmpeg -f avfoundation` で 60 コマ/秒
- 動きの長さ: 前後のコマの差を測り、変化が続いた長さを見た
- 動きを見るために、受信トレイにテスト用のタスクを 3 件足し、終わってから削除した

数値の単位はポイント (pt)。所有者のプロジェクト名とタスク名は書き写していない。

あわせて Web で調べた (ログインなし):
- Todoist のヘルプセンター
- Doist の公開部品集 `@doist/reactist` 37.4.0 (npm)

## 1. 配置

- 左の一覧:
  - 幅 280
  - 背景は #FCFAF8 付近 (写真の画素で確認)
  - 上から順に: ベルと左の一覧の開閉ボタン、アカウント名、「タスクを追加」(赤い丸に白い +)、検索、インボックス、今日、近日予定、レポート、オプション、マイプロジェクト
  - プロジェクトは色付きの「#」と名前。件数は右寄せの灰色
  - 子のプロジェクトは 1 段字下げする
  - 親のプロジェクトには、マウスを乗せると開閉の「∨」が出る
- 選んでいる項目: 薄い赤の背景に、赤い文字とアイコン。件数も赤
- 中央:
  - 幅 800 の列を、左の一覧を除いた領域の真ん中に置く
  - 上の帯は、左に戻る・進む、右に「表示」とコメントと「…」
- 見出し:
  - 大きく太い題名 (例「今日」)
  - その下の行に「✓ 6 件のタスク」(今日の画面)
- セクションの見出し:
  - 「∨」(列の左外)、太字の名前、右端に操作 (例「リスケジュール」は赤)、下に区切り線
  - セクションの間には、日付の見出し (例「10月25日・今日・日曜日」) が並ぶ

## 2. タスクの行

- 行と行の間は 1 本の細い区切り線
- 行の高さ:
  - 1 段 (名前だけ) は約 43
  - 2 段 (名前と期日など) は約 59
- チェック:
  - 丸、直径約 18
  - 優先度は縁の色と、薄い同じ色の塗り。P1 赤、P2 オレンジ、P3 青、P4 灰の縁で塗りなし
  - マウスを乗せると、丸の中に灰色のチェックが出る
- 2 段目:
  - 期日 (カレンダーのアイコンと日付)、繰り返しのアイコン、サブタスクの数 (アイコンと「0/2 >」)
  - 期日の色は、期限切れが赤、今日が緑、明日が茶、7 日以内が紫、それより先は色なし (ヘルプセンターによる)
- 右端の 2 段目:
  - プロジェクト名と「#」(今日・近日など、プロジェクトをまたぐ画面)
  - セクションのあるプロジェクトでは「プロジェクト / セクション #」
- マウスを乗せた行:
  - チェックの左 (約 29 左) に、6 点のドラッグの持ち手
  - 1 段目の右に、編集 (鉛筆)・日付・コメント・「…」
  - 行の背景は変わらない
- キーボードで選んだ行: 角の丸い薄い枠
- サブタスク:
  - 1 段の字下げは約 28
  - 親には列の左外に「∨」、2 段目に「サブタスク数 0/1」
- 「…」のメニューの項目:
  - タスクを上に追加、タスクを下に追加、編集 (⌘E)
  - 日付の早押し (今日・明日・週末・…)、優先度の旗 4 つ
  - 期限、リマインダー、次へ移動 (V)、複製、リンクをコピー、新しいウインドウで開く、拡張機能、削除 (⌘⌫)
- 「タスクを追加」(列の末尾):
  - 赤い「+」と灰色の文字
  - 押すと、その場で枠の付いた入力欄に変わる
  - 入力欄は、名前の行、「+」、日付・優先度・プロジェクトの小さな札、右に「×」と赤い丸の「↑」(追加)
  - Enter で追加して入力欄は開いたまま。Esc で閉じる (書きかけがあると「保存されていない変更を破棄しますか?」)
- 追加・完了のあと、左下に黒いお知らせが出る:
  - 例「タスクが インボックス に追加されました 開く ×」
  - 例「1 件のタスクを完了しました 元に戻す ×」

## 3. タスクの詳細 (行をクリック)

- 画面中央のダイアログで開き、後ろは暗くなる
- ウィンドウ 1512×949 のとき、大きさ約 862×818 (上下に約 65 の余白)
- 上の帯:
  - 左に「プロジェクト / セクション」
  - 右に前のタスク「∧」、次のタスク「∨」、「…」、閉じる「×」
- 左の欄:
  - チェックと大きな名前、その下に「説明」
  - 「+ サブタスクを追加」、コメントの入力欄
- 右の欄:
  - 幅約 257、背景は左の一覧と同じ色
  - 項目はプロジェクト、日付、期限、優先度 (P4)、ラベル、リマインダー、位置情報。それぞれ区切り線で分ける

## 4. 狭いウィンドウ

- 幅 760 では、左の一覧を出したまま中央を狭める
- 幅 750 前後より狭いと、左の一覧を自動で隠す:
  - 開閉のボタンは、上の帯の左 (戻る・進むの左) に移る
  - 開くと、画面を暗くした上に重なって出る。Esc で閉じる
- 幅 400 まで狭めても、中央の列は崩れずに縮む

## 5. 動き (60 コマ/秒の動画で測定)

| 操作 | 動き |
|---|---|
| 行にマウスを乗せる | ドラッグの持ち手と右のボタンが、その瞬間に出る (ふわっと出ない) |
| セクションの開け閉め | すぐ切り替わる (高さの動きも矢印の回転もない) |
| タスクを開く | ダイアログと暗い背景が約 0.1 秒で出る |
| タスクを閉じる | 約 0.03〜0.08 秒で消える |
| 詳細の前後のタスクへ移る | 中身が一瞬で入れ替わる (動きなし) |
| 左の一覧を隠す・出す | 約 0.3 秒ですべり、中央の列も一緒に真ん中へ動く |
| ドラッグで並べ替え | 押して約 0.25 秒で持ち上がる (下記) |
| ドラッグで字下げ | 右へ動かすと赤い線が 1 段右から始まる |
| 完了 | チェックが入り、約 0.25 秒後に行が消えて下の行が詰まる (約 0.1 秒)。左下に「元に戻す」付きのお知らせ |

ドラッグで並べ替えるときの様子:
- 持ち上がった行は、影の付いたカードになって少し右にずれ、指に付いてくる
- 他の行は動かない
- 落とす位置に、左端に小さな丸の付いた赤い横線が出る
- 離すとカードがその位置に収まる (約 0.3 秒)

ドラッグで字下げするときの様子:
- 右へ動かすと、赤い線が 1 段右 (サブタスクの位置) から始まる
- 離すと、すぐ上のタスクのサブタスクになる。親に「∨」と「0/1」が付く
