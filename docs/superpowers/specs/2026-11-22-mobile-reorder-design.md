# iPhone の長押しで並び替え (2026-11-22)

iPhone のプロジェクトと受信トレイの一覧で、行を長押ししたまま動かして並び替える。

## 操作

- 行を 500 ms 長押しすると、行が持ち上がる (影がつき、指に付いてくる)。展開した子の行も一緒に動く。
- 持ち上げたまま 8 px 以上動かすと並び替えになる。落ちる先に赤い線を出す。離すとそこへ移す。
- 動かさずに離すと、今までどおり行のメニューを開く。
- 一覧の上下の端に近づくと、一覧がスクロールする。
- 持ち上げている間は、一覧はスクロールせず、引っ張って更新もしない。

## 落ちる先

デスクトップのドラッグ (仕様 ③ §3.1-3.3、`dropTarget.ts` の `computeDrop` と `placementOf`) と同じ計算を使う。違いは 1 つ。

- 指で行が隠れるので、行の真ん中に落としても「その行の子にする」にはしない。近いほうの行の間にする (`mobileReorder.ts` の `mobileDrop`)。子にするのは、指を右へ動かしたとき (28 px で 1 段) だけ。

保存は `move_task_within` (デスクトップのドラッグと同じ)。セクションの末尾の「タスクを追加」の行は、そのセクションの末尾に落とす場所になる。

## 対象外

- 今日、近日、ラベルの一覧の並び替え (デスクトップでも並びの決め方が違う)。
