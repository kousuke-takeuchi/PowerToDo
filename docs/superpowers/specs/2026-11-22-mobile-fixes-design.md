# iPhone の直し (2026-11-22)

iPhone を使って見つかった 4 件を直す。

## 1. クイック追加で日付、優先度、プロジェクトを選べない

**今**: クイック追加の下の行のチップ (日付、優先度、プロジェクト、その他の中のラベル) は、入力欄の末尾に語 (`明日`、`p1`、`#`、`@`) を足すだけで、選ぶための一覧が出ない。

**直し**: チップを押すと、クイック追加のカードの上にシートを重ねて一覧を出す (リマインダーと同じ重ね方。カードは 0.95 に縮めて暗くする)。選んだものは入力欄の語として書き込み、同じ種類の語がすでにあれば置き換える。入力欄が正のまま (構文はデスクトップと同じ) なので、手で打った語と混ざっても同じに読む。

| チップ | シート | 書き込む語 |
|---|---|---|
| 日付 | 日付のシート (今日、明日、今週末、来週、日付なし、カレンダー) | `今日` `明日` `今週末` `来週`、カレンダーは `M/D` (今年) か `YYYY/M/D`。時刻を選んだら後ろに `H:MM`。日付なしは日付、時刻、繰り返しの語を消す |
| 優先度 | 優先度のシート | `p1` から `p3`。P4 は語を消す (既定が P4) |
| プロジェクト | 移動のシートと同じ一覧 (プロジェクト、今のプロジェクトのセクション) | 開いている画面のプロジェクトなら `#` の語を消し、ほかは `#名前` (空白を含む名前は `#"名前"`)。セクションを選ぶと、そのセクションに入れる (クイック追加の構文にセクションは無いので、入力欄には書かない) |
| ラベル | ラベルのシート (付け外し、開いたまま) | `@名前` を並べ直す |

置き換えは、`parse_quick_add` が返す語の位置 (spans) を使う純粋な処理 (`quickAddInsert.ts`) にする。

## 2. サブタスクが多いと「サブタスクを追加」が押せない

**原因**: タスク詳細の本文が `flex: 1; min-height: 0` で画面の高さに縮み、はみ出したサブタスクの上に、すぐ後ろのコメント欄が重なる。

**直し**: 本文は縮まない (`flex: 1 0 auto`) ようにし、コメント欄はスクロールの下端に貼り付ける (`position: sticky; bottom: 0`、背景つき)。Todoist と同じく、コメント欄は常に下に見え、本文はその上でスクロールする。

## 3. セクションと、セクションのタスクを追加できない

**直し**

- プロジェクト画面の上の帯の「…」(受信トレイにも出す) に「セクションを追加」を足す。名前のシート (TextSheet) で名前を入れる。受信トレイでは「名前を変更」「削除」は出さない。
- 各セクションの末尾と、セクションの無いタスクの末尾に「タスクを追加」の行を出す。押すとクイック追加が開き、そのセクションに入れる。
- 展開した親の下の「サブタスクを追加」は、今は普通のタスクを足してしまう。押すとクイック追加を開き、その親のサブタスクとして入れる。
- クイック追加のコマンド (`quick_add`) に、入れる先のセクションと親 (`section`、`parentNo`、省略可) を足す。`#` で別のプロジェクトを選んだときは使わない。プロジェクトのチップには「プロジェクト / セクション」と出す。

## 4. 左のメニュー (ドロワー)

デザインを作り、承認を得てから実装する (M-11)。

- 一番上の画面 (受信トレイ、今日、近日、閲覧) の上の帯の左に、メニューのボタン (三本線) を置く。押すと左からドロワーが出る。
- 中身はデスクトップのサイドバーと同じ順: 同期の状態、検索、受信トレイ、今日、近日、ラベル、マイプロジェクト (件数つき)、設定。
- 項目を押すと、その画面へ移ってドロワーを閉じる。背景を押すか、左へ払うと閉じる。
- 下のタブは残す。
