## 1. 目的と範囲

所有者の言葉 (2026-10-26):
- 今回デザインをアップデートしたが、iOS アプリも同じくアップデートしたい
- お手本は Todoist の iPhone 版。色と部品はデスクトップと共通
- 動画も確かめて、アニメーションの様子もまねる

iPhone の作り直しは 4 つに分け、それぞれ設計書 → 計画 → 実装の PR にする。順番は ④ → ① → ②③ → ⑤。本書は ④。
- ④ 見た目: 画面の移り方、上下の帯、行、見出し、シートの枠、クイック追加、お知らせ、動き。本書
- ① タスクの画面を下から出るシートにし、コメントを読む・書く
- ②③ 行の操作 (長押しのメニュー、選択モード) と長押しでの並べ替え・字下げ。今のスワイプは残す
- ⑤ 表示メニュー (並び替え、グループ、フィルター、完了したタスク。設定はデスクトップと同期)

含むもの (iPhone だけ):
- 下のタブを Todoist と同じ 4 つにし、ドロワーをやめて「閲覧」タブを作る
- 大きな見出しと、スクロールで上の帯へ縮む動き
- 上の帯の右のボタン、追加ボタン
- iOS 26 の「ガラス」(半透明でぼかした浮いた丸い形)
- 行、チェックボックス、2 段目、サブタスク、区切り線、セクションと日付の見出し
- シートの枠と動き (今あるシートすべて)
- クイック追加の見た目と候補の出し方
- 完了などのあとの「元に戻す」付きのお知らせ
- ダークモード
- design.pen の iPhone の画面

含まないもの:
- タスクの画面の作り (① で下から出るシートにする)。本書では今の全画面のまま、文字の大きさと余白だけそろえる
- 長押しのメニュー、選択モード、並べ替え (②③)
- 表示メニュー (⑤)。「表示」のボタンも ⑤ で足す
- デスクトップの見た目 (変えない)
- Todoist のロゴ、アイコンの素材、名前 (アイコンは今の lucide のまま。タブの名前は PowerToDo の呼び方)

成功基準:
- 390x844 の画面一覧で、次が調査の値と ±2pt で合う: タブの帯の大きさと位置、追加ボタンの大きさと位置、大きな見出しの大きさ、左右の余白、チェックボックスの大きさ、行の高さ (2 段 63、1 段 48)、サブタスクの字下げ
- 下のタブは「受信トレイ / 今日 / 近日 / 閲覧」で、ドロワーとハンバーガーが無い。プロジェクト、ラベル、検索、設定は閲覧タブから開ける
- スクロールすると大きな見出しが上の帯の中央の小さな見出しへ移り、戻すと元に戻る
- シートは約 0.37 秒で開き、約 0.13 秒で閉じる。跳ね返りは無い
- 完了、日付の変更、移動のあとに「元に戻す」付きのお知らせが出て、押すと戻る
- ダークモードと動きを減らす設定 (prefers-reduced-motion) でも崩れない
- デスクトップの画面は変わらない (今の画面一覧のストーリーで確かめる)

## 2. 作り方 (案 A)

共通の部品 (`TaskRow`、`Checkbox`、`SectionHeader`、`SidebarItem`、`ProjectItem`) はすでに `variant="mobile"` か `mobile` の分岐を持つ。デスクトップの ④ で、iPhone は前の見た目のまま残してある。本書はその分岐の値だけを変える。デスクトップの分岐には触れない。

iPhone にしかない部品は書き直す:
- `MobileShell`、`MobileHeader`、`TabBar`: 上下の帯、追加ボタン
- `BottomSheet`、`SheetFrame` と各シート: 枠と動き
- `MobileQuickAddSheet`: クイック追加
- `Drawer`: やめる。中身は新しい `MobileBrowse` (閲覧タブ) へ移す

新しく作るもの:
- `Glass`: 半透明の背景を後ろごとぼかす部品。`backdrop-filter` (と `-webkit-backdrop-filter`) と半透明の背景色。タブの帯、上の帯の右のボタン、シートの × と ✓ に使う
- `MobileBrowse`: 閲覧タブ
- 見出しの縮み具合を出す純粋な関数 (スクロール量 → 0〜1)。テストを付ける

案 B (iPhone 用の部品を別に作る) は、日付の出し方などがデスクトップと二重になるので採らない。案 C (寸法を設定値の 2 組にまとめる) は、デスクトップの部品も書き換えることになり範囲を超えるので採らない。

## 3. 画面の移り方と上下の帯

### 3.1 下のタブ
- 「受信トレイ / 今日 / 近日 / 閲覧」の 4 つ
- 形: 浮いたガラスの丸い帯 1 本。画面の左右から 28 ずつ空け、高さ 58、画面の下 (安全域の上) から 23
- 各タブ: アイコン (22) の下に 10pt の文字
- 選んでいるタブ: 灰色の丸い下地、アイコンと文字は赤 (`--color-accent`)
- 今日のアイコンには今日の日の数字を入れる
- 受信トレイのタブは受信トレイのプロジェクト画面を開く

### 3.2 閲覧タブ
- 上の帯の右に、ガラスの丸い帯の中に検索と設定のボタン
- 上から:
  - 同期の状態の行 (今のドロワーの `SyncStatus`)。押すと今すぐ同期
  - 「マイプロジェクト」の見出し (15pt 太字)
  - プロジェクトの一覧: 色付きの `#`、名前、件数 (12pt 灰色)。受信トレイは出さない (タブにある)
  - 「ラベル」の行。押すと今のラベルの一覧
- 今の検索タブ (`MobileSearch`) と一覧タブの中身は、ここから開く画面になる
- Todoist の閲覧タブの写真は無いので、並びは Todoist のヘルプと今のドロワーの中身から決めた

### 3.3 画面の見出し
- 受信トレイ、今日、プロジェクト、ラベル:
  - 左上に大きな見出し 34pt 太字。下に 12pt 灰色で「n 件のタスク」
  - スクロールすると、見出しは上の帯の中央に 17pt 太字で移り、件数は 11pt で下に付く
  - 動きはスクロール量に合わせる (時間では動かさない)。大きな見出しの高さぶんスクロールしたところで小さな見出しに切り替わり終わる
- 近日: 最初から中央の 17pt の見出し。その下に「2026年10月 >」の行と週の帯。帯の下のつまみを下に引くと月の表に開く (今の `WeekStrip` をこの形に直す)

### 3.4 上の帯の右のボタン
- ガラスの丸い帯の中に「…」。「…」は今の「その他」のメニューを開く
- 「表示」のボタンは ⑤ で同じ帯に足す (iPhone には今、表示のメニューが無い)
- 今の同期のボタンは閲覧タブの同期の行へ移す。下に引いて同期する操作は残す

### 3.5 追加ボタン
- 赤い丸 (`--color-accent`)、直径 62、白い + (26)
- 右から 18、タブの帯のすぐ上。スクロールしても消さない
- 影は今の `--shadow-fab`

### 3.6 ガラス
- 明るいとき: 白の半透明 (不透明度 約 0.7) + ぼかし 20 + 細い明るい縁
- ダークモード: 暗い灰色の半透明 + 同じぼかし
- `backdrop-filter` が効かない環境では、不透明の背景色に落とす

## 4. 行と見出し

### 4.1 行 (`TaskRow` の `mobile` の分岐)
- 左右の余白 15 (画面の余白)
- チェックボックス (`Checkbox` の 22): 直径 22、輪の太さ 2
  - 優先度 1〜3: 輪を赤・橙・青にし、中を同じ色で薄く塗る (デスクトップと同じ約 10% の色)
  - 優先度 4: 灰色の輪、中は塗らない
- タスク名: 16pt、1 行。チェックボックスの右 12 から (左端 49)
- 説明: あればタスク名の下に 13pt 灰色で 1 行
- 2 段目 (12pt): サブタスクの数 (枝のアイコン + 「0/2」)、日付 (期限切れは赤、今日は緑)、繰り返しのアイコン、コメントの数 (吹き出し + 数)。右端に灰色でプロジェクト名と色付きの `#` (受信トレイは受信トレイのアイコン)
- 行の高さ: 2 段目があるとき 63、タスク名だけ 48
- 区切り線: 細い線 (`--color-border`)。文字の左端 (49) から右の余白まで。チェックボックスの下には引かない

### 4.2 サブタスク
- 子のチェックボックスを親のタスク名の左端にそろえる (字下げ 約 40)
- サブタスクのある親は、タスク名の行の右端に開閉のシェブロン。今の「1/3」のバッジを押して開く形はやめる (数は 2 段目に出る)
- 開閉はすぐ切り替える。今の高さが伸び縮みする動きはやめる

### 4.3 見出し (`SectionHeader` の `mobile` の分岐)
- セクションと日付の見出し: 15pt 太字、線なし、上に 36 の間
- 今日の「期限切れ」: 同じ行の右に赤い「再スケジュール」とシェブロン。今の別の行は 1 行にまとめる
- プロジェクトのセクション: 右に「…」(メニューの中身は ②③。本書では今のセクションのメニューを開く)
- 近日の日付の見出し: 「10月26日 · 今日 · 月曜日」の形

### 4.4 完了
- 行が消えるまでの動きはデスクトップと同じ約 0.25 秒 (完了の動きは動画に写っていないため)
- 消えたあと、お知らせ (§5.4) を出す

## 5. シート・クイック追加・お知らせ

### 5.1 シートの枠 (`BottomSheet`、`SheetFrame`)
- 日付、優先度、ラベル、移動、リマインダー、メニュー、文字入力の今あるシートすべて
- 上の角の丸み 16、つまみ 36x4
- 左上にガラスの丸い ×。決定が要るシートは右上に赤い丸い ✓。題名は中央に 17pt 太字
- 中身の項目は、薄い灰色の下地の上に白い角丸 (16) のカードとしてまとめる

### 5.2 シートの動き
- 開く: 下から約 0.37 秒。最初の 0.1 秒で 7 割進み、ゆっくり止まる。跳ね返りなし (ばねの動き、減衰 1)
- 閉じる: 約 0.13 秒で下へ。だんだん速くなる (ease-in)。× でも下に払っても同じ
- 後ろの画面はシートの動きに合わせて暗くなる
- 重なるとき: 下のシートが少し縮んで (約 0.95 倍) 暗くなる
- 大きなシート: 85% の高さで止まり、上に引くと約 0.2 秒で全画面になる
- 動きを減らす設定のときは、動きなしで出し入れする

### 5.3 クイック追加 (`MobileQuickAddSheet`)
- 画面の下に張り付けず、キーボードのすぐ上に浮いた白いカード (角の丸み 24、左右の余白 10)
- 名前の欄 20pt
- 下の段: 「＋」、日付 (今日なら緑)、優先度、プロジェクトのボタン。右に赤い丸い送信ボタン (36)
- `#` や `!!` を打つと、候補をカードの上に浮いたカードで出す (プロジェクトの一覧、旗の色付きの優先度)。候補の中身と選び方は今のまま

### 5.4 お知らせ (`Toast`)
- タブの帯のすぐ上に白いカード。左に「元に戻す」(赤) とアイコン、その下に説明 (例: 「今日 にスケジュールしました」)
- 下から出て、3 秒で消える
- 完了、日付の変更、移動のあとに出す。「元に戻す」で前の状態に戻す

### 5.5 タスクの画面 (① までのつなぎ)
- 今の全画面のまま。題名を 19pt の太字にし、項目の文字と余白を本書の値にそろえる

## 6. ダークモード
- Todoist のダークモードの写真は無い。色は今のダークテーマの値をそのまま使う
- ガラスは暗い半透明 (§3.6)
- シートの下地とカードは、今の暗い背景の 2 段階の色で分ける

## 8. 確かめ方
- 純粋な関数 (見出しの縮み具合など) に node のテスト
- `npm run test:web`、`npm run build-storybook` と `npm run check:stories` (`missing: none`)
- 画面一覧を 390x844 で撮り、調査の値と比べる。シートの開閉と見出しの縮みは画面一覧の上で動かして確かめる (CDP)
- デスクトップのストーリーを撮り、変わっていないことを確かめる
- 実機: 所有者の iPhone で TestFlight。ノッチと安全域、キーボードの上のクイック追加、ガラスのぼかしの重さ、スクロールの滑らかさ。PR に手動チェック表を付ける
