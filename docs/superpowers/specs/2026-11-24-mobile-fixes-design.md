# iPhone の直し (2026-11-24)

| 件 | 直し |
|---|---|
| サブタスクを編集できない | 親のタスクの画面で、サブタスクの行を押すとそのサブタスクの画面を開く。戻るで親の画面に戻る |
| 今日の画面で足すタスクの日付 | 今日の画面の追加ボタンは、入力欄に「今日 」が入った状態で開く (Todoist と同じ) |
| メニューを左端から開く | タブの画面で、画面の左端 (14 px) から右へ 40 px 以上払うとメニューが開く。行のチェックボックス (左 15 px から) にはかからない |
| 時刻を指定できない | 日付のシートに「時刻」の行を足す。iPhone の時刻のホイール (`input type=time`) で選ぶ。日付が無いときは今日にする。「時刻なし」で外す |
| 「毎月月末」を読めない | 「毎月月末」「毎月 月末」「毎月最終日」「毎月 最終日」「月末日」を、毎月の最終日 (`BYMONTHDAY=-1`) として読む |
| 今日、近日で並び替えできない | 今日: 「今日」のグループを長押しで並び替える (保存はデスクトップと同じ `set_today_order`)。期限切れの行は並び替えない。近日: 長押しで別の日のグループへ動かすと、その日に変える (時刻は残す)。同じ日の中の順は保存しない (近日の順は決まっている) |
| デスクトップのポップアップが下で切れる | ポップアップを、ウィンドウではなく、はみ出しを切る一番近い枠 (タスクのダイアログ) の中に収める。収まらなければ中をスクロールする |

## 今日と近日の「表示」(2026-11-24 追記)

今日と近日の右上に「…」を置き、押すと「表示」のシートが開く (デスクトップの「表示」と同じ設定。共通ファイルの同じ行 `表示:今日` / `表示:近日` を読み書きするので、端末をまたいで同じになる)。

- 並び替え: 手動、名前、時刻、追加日、優先度 (日付は、今日が 1 日、近日が日ごとなので出さない)。手動以外は並び順 (昇順、降順) を選べる。
- グループ (今日だけ): なし、優先度、ラベル、プロジェクト。
- 優先度の絞り込み: すべて、P1 から P4。隠した件数は一覧の末尾に出し、押すとシートを開く。
- 期限切れは並びを保ち、絞り込みだけかける (デスクトップと同じ)。近日は、各日の中だけを並べる。
- 手動以外、グループ、絞り込み中は、今日の長押しの並び替えを止める (長押しはメニュー)。
- 「時刻」の並び替えを、デスクトップの「表示」にも足す (`sort=time`。時刻なしは昇順でも降順でも最後)。古い版は知らない値を「手動」として読むので、壊れない。
