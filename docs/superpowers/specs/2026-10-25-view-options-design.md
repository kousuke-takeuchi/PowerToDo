## 2. 「表示」メニュー

### 2.1 見た目
- 上の帯の右の「表示」(ボードのときは「ボード」) を押すと、ボタンの下・右揃えに幅 260 のメニューを出す
- 上から:
  1. レイアウト: 「リスト」「ボード」の 2 つの大きなボタン (プロジェクトの画面だけ)
  2. 完了したタスク: 切り替え
  3. 並び替え (たためる見出し): グループ、並び替え、並び順 (昇順・降順。並び替えが手動のときは出さない)
  4. フィルター (たためる見出し): 日付、作成日、優先度
  5. 既定から変えた項目があるときだけ、末尾に「リセット」
- 各選択は右寄せの枠 (幅 140)。押すと下に選択肢を出し、今の値に「✓」
- 既定から変えた値の枠は文字を `--color-accent` にする
- 「表示」ボタンは、既定から変えているとき右上に小さな点 (`--color-accent`、直径 6) を付ける
- Esc か外を押すと閉じる。変更はすぐ画面に反映し、保存する

### 2.2 選択肢

| 項目 | 選択肢 | 既定 |
|---|---|---|
| 並び替え | 手動 / 名前 / 日付 / 追加日 / 優先度 | 手動 |
| 並び順 | 昇順 / 降順 | 項目ごとの自然な向き (名前・日付は昇順、追加日は新しい順、優先度は P1 が先) |
| グループ | なし / 日付 / 追加日 / 優先度 / ラベル | なし |
| 日付 (フィルター) | すべて / 今日 / 今週 / 次の 7 日間 / 今月 / 次の 30 日間 / 日付なし | すべて |
| 作成日 (フィルター) | すべて / 今日 / 過去 7 日間 / 過去 30 日間 | すべて |
| 優先度 (フィルター) | すべて / P1 / P2 / P3 / P4 | すべて |
| 完了したタスク | 表示 / 隠す | 隠す |
| レイアウト | リスト / ボード | リスト |

### 2.3 画面ごとに出す項目

| 画面 | レイアウト | 完了 | 並び替え | グループ | フィルター |
|---|---|---|---|---|---|
| プロジェクト | ○ | ○ | ○ | ○ | 日付・作成日・優先度 |
| 今日 | — | — | ○ (手動 = 今日の並び) | なし / 優先度 / ラベル / プロジェクト | 優先度 |
| 近日 | — | — | ○ (各日の中で) | — (日ごとの見出しのまま) | 優先度 |
| ラベル | — | ○ | ○ | なし / 日付 / 優先度 / プロジェクト | 日付・優先度 |

- 今日・ラベルの「プロジェクト」グループは、プロジェクトの並び順で見出しを作る
- 近日の「手動」は今の順 (優先度、No.) のまま

## 3. 並べ方

### 3.1 フィルター
- 合わないタスクを隠す。サブタスクは親と一緒に扱う (親が合えば子も出す。子だけが合うときは親を出さない)
- 「今週」は週の開始 (設定の「週の開始」) から 7 日。「次の 7 日間」は今日から 7 日
- 隠したタスクがあるとき、見出しの下に「<n> 件を隠しています (フィルター)」を灰色で出す

### 3.2 並び替え
- 最上位のタスクにだけ使う。サブタスクは親の下で、今の手動の並び (並び順) のまま
- 同じ値のときは手動の並び、それも同じなら No. の順
- 「日付」で日付の無いタスクは、昇順でも降順でも最後
- 「名前」は Unicode の照合 (`localeCompare` の `ja`)

### 3.3 グループ
- プロジェクトの画面でグループが「なし」以外のときは、セクションの代わりにその項目で見出しを作る (セクションは使わない)
- 見出し:
  - 日付: 期限切れ / 今日 / 明日 / 日付ごと (「10月28日 · 水曜日」) / 日付なし
  - 追加日: 今日 / 昨日 / 日付ごと
  - 優先度: 優先度 1 〜 4
  - ラベル: ラベルの並び順。ラベルが複数あるタスクは各ラベルの下に出す。ラベルの無いタスクは「ラベルなし」
  - プロジェクト (今日・ラベル): プロジェクトの並び順
- 見出しはたためる (たたんだ状態はその画面の中だけで、保存しない)
- グループの中は 3.2 の並び替え

### 3.4 完了したタスク
- 「表示」のとき、最上位の完了したタスクを今の「完了したタスクを表示」の場所 (一覧の末尾) に出す。今あるボタンは残し、メニューと同じ状態を切り替える

## 4. ボード (プロジェクトの画面)

- 列: 未分類 (タスクがあるときだけ)、各セクション、完了 (完了したタスクを「表示」のとき)
- 列の幅 272、間 16。列の見出しはセクション名と件数。横にスクロールする
- カード: 今の TaskRow (行の操作 ② と同じボタン)。サブタスクはカードの下に「n/m」だけ出す (カードの中には並べない)
- 列の末尾に「タスクを追加」(② の編集欄)
- 並べ方: 列の中は 3.2 の並び替え。フィルターも効く。グループは使わない (メニューで選べない)
- ドラッグ (③ の仕組み):
  - 手動のとき: 列の中の並べ替えと、列の間の移動 (セクションが変わる)
  - 自動の並びのとき: 列の間の移動だけ (列の末尾に入る)
  - 左の一覧への落とし込みは、リストと同じ

## 5. 自動の並びとドラッグ

- 並び替えが「手動」でないとき、またはグループが「なし」でないときは、並べ替えのドラッグ (赤い線・行に重ねる・字下げ) をしない
- 持ち手を押すと、左下に「手動の並び (グループなし) に戻すと並べ替えられます」のお知らせを出す (② のお知らせ。ボタンは「戻す」で、並び替えを手動・グループをなしにする)
- 左の一覧のプロジェクトへの落とし込みと、近日での日またぎは使える
- ⌥↑ / ⌥↓ と Ctrl+] / Ctrl+[ も同じく止め、同じお知らせを出す

## 6. 保存と同期

- 共通ブック (`_PowerToDo.xlsx`) の「設定」シートに、画面ごとに 1 行
  - キー: `表示:プロジェクト:<名前>`、`表示:今日`、`表示:近日`、`表示:ラベル:<名前>`
  - 値: `;` で区切った `名前=値` (例 `layout=board;done=1;group=label;sort=priority;dir=desc;date=7d;created=all;prio=all`)
  - 既定と同じ項目は書かない。すべて既定なら行を消す
- 「設定」シートの知らないキーは、今も読み書きの間で保たれ、同期ではキーごとに合わせている。そのまま使う
- 知らない名前・値は無視して既定として読む (新しい版で増えた項目を古い版が壊さない)
- プロジェクト・ラベルの名前を変えたらキーも付け替える。プロジェクト・ラベルを消したら行を消す
- 変更は 0.5 秒待ってまとめて保存する (切り替えを続けて押したとき)

## 8. 部品 (目安)

- `src/app/view/viewOptions.ts` (新規、純粋): 設定の型、既定、文字との相互変換 (`parse` / `format`)、画面ごとの選べる項目
- `src/app/view/arrange.ts` (新規、純粋): `(タスク, 設定, 今日, 週の開始, ラベル・プロジェクトの並び) → { groups: { key, title, tasks }[], hidden: number }`
- `src/views/ViewMenu.tsx` (新規): メニュー (今の `HeaderActions` の「表示」から開く)
- `src/views/BoardView.tsx`: 実データ・② の行の操作・③ のドラッグにつなぐ
- `ProjectView`・`TodayView`・`UpcomingView`・`LabelDetailView`: `arrange` の結果で描く。グループ / 自動の並びのときドラッグを止める
- Rust: 「設定」シートの `表示:` 行を読み書きするコマンド (`view_options` / `set_view_options`)、名前の変更・削除での付け替え。今の `extra_settings` の仕組みを使う

## 9. テスト

自動:
- `viewOptions`: 文字との相互変換 (既定は書かない、知らない名前は無視)
- `arrange`:
  - フィルター (各日付の範囲、週の開始、日付なし、作成日、優先度、親と子)
  - 並び替え (各項目と向き、同じ値のとき、日付なしは最後)
  - グループ (各項目の見出しと順、複数ラベル、ラベルなし)
- Rust: `表示:` 行の読み書き、プロジェクト・ラベルの名前の変更と削除での付け替え、同期で他の PC の行が届く

手動 (PR 本文のチェックリスト):
- プロジェクトで並び替え・グループ・フィルター・完了・リセット、別の PC で同じ表示
- ボードで列の間のドラッグ、自動の並びのときの列の中
- 自動の並びで持ち手を押す → お知らせ → 「戻す」
- 今日・近日・ラベルの「表示」
