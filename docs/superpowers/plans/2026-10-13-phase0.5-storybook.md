# Phase 0.5: Storybook 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** pen の 40 画面を React コンポーネントにし、Storybook でライト / ダーク・幅 1440 / 960 / 390 を切り替えながら開閉・選択の操作を確認できる状態にする。

**Architecture:** Tauri 2 の雛形 (React + TypeScript + Vite) をリポジトリ直下に展開し、`src/` に Storybook を同居させる。pen の変数は CSS カスタムプロパティ、pen の component は `src/components/` に 1 対 1、画面は `src/views/` の組み合わせ、Story は `src/stories/screens/` に画面 1 枚 = 1 Story。視覚仕様は `design.pen` (pen MCP で読む) と `design/storyboard.md`。

**Tech Stack:** create-tauri-app 4.7.5 (Tauri 2, react-ts), React 19.3, Vite, TypeScript, Tailwind CSS 4.3 (`@tailwindcss/vite`), Storybook 10.6 (Vite builder, react-vite), lucide-react 1.56, Noto Sans JP (Google Fonts)。バージョンは 2026-10-13 の `npm view` の結果。`npm install` の実際の解決結果を Task 1 の report に記録する。

**Spec:** `docs/superpowers/specs/2026-10-13-phase0.5-storybook-design.md` (全体設計 `docs/superpowers/specs/2026-10-13-powertodo-overall-design.md`、Phase 0 `docs/superpowers/specs/2026-10-13-phase0-pen-design.md`)

## Global Constraints

- 視覚仕様は `design.pen`。各タスクの実装者は pen MCP (`mcp__pencil__execute` with `filePath: "/Users/ktakeuchi/Documents/PowerToDo/design.pen"`, read-only の `Get` / `TakeScreenshot` のみ) で該当ノードを読み、寸法・色・文言をそのまま使う。pen を変更しない。画面名 → pen id は `design/storyboard.md` の画面一覧
- 色・間隔・角丸は必ず CSS カスタムプロパティ (`--color-*`, `--space-*`, `--radius`) 経由。コンポーネント内に hex を書かない (例外: pen と同じ `#FFFFFF` のボタン文字、D-08b の OS 通知モック)
- フォントは全テキスト `var(--font-body)` = "Noto Sans JP"
- `src/components/*` は内部状態を持たない (props のみ)。`src/views/*` は spec §5 の開閉・選択状態だけ `useState` で持つ。データ変更のロジックは書かない
- Story 名は pen のノード名と完全一致 (例 `D-01 プロジェクト`, `M-01b サブタスク展開`)。Storybook の title は `Screens/Desktop/<名前>`, `Screens/Dark/<名前>`, `Screens/Mobile/<名前>`, `Components/<名前>`
- 幅: デスクトップ 1440×900、最小 960×600、モバイル 390×844。サイドバー 280、中央カラム最大 800、詳細パネル 400、モバイルの下部タブ 56 + 34
- lucide のアイコン名は pen と同じ (`ellipsis`, `circle-plus`, `triangle-alert`, `clock-3`, `funnel`, `file-x`, `circle-check`, `loader-circle` など)。lucide-react ではパスカルケース (`Ellipsis`, `CirclePlus`, `TriangleAlert`, `Clock3`, `Funnel`, `FileX`, `CircleCheck`, `LoaderCircle`)
- サンプルデータは `src/mock/data.ts` に 1 か所。文言は `design/storyboard.md` と pen の画面に合わせる。実在の識別子は使わない (`たろう`, `user@example.com`, `nas.local`)
- `npm run storybook` と `npm run build-storybook` が警告なしで通る状態を各タスクの終わりで保つ
- コミットは対象ファイルを明示して行う。`Co-Authored-By` などの attribution trailer は付けない。ブランチ `feature/phase0.5-storybook` (origin/main から `--no-track` で作成)。push は `git push origin feature/phase0.5-storybook:refs/heads/feature/phase0.5-storybook`。PR base は main
- `src-tauri/` は雛形のまま (Task 1 で生成するだけ)。`cargo` は実行しない (Phase 1 で)

      {!mobile && (
