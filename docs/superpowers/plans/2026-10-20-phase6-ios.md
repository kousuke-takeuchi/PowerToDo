# Phase 6 (iPhone 版: Tauri iOS、アプリ内 Tailscale、モバイル画面、ローカル通知、Google) 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 所有者の iPhone で PowerToDo を動かし、NAS (アプリ内 Tailscale 経由の WebDAV) か Google Drive でデスクトップと同期できるようにして、TestFlight で入れられる形にする。

**Architecture:** 同じ Rust の中身 (`src-tauri`) と React の画面を Tauri 2 の iOS ターゲットでビルドする。デスクトップ専用の機能は `#[cfg(desktop)]` で外す。NAS へは `tailnet/` の Go を iOS 用 c-archive (`libtailnet.a`) にしてアプリ内で動かし、Rust の `InProcTailnet` がデスクトップのサイドカーの `Tailnet` と同じ形で `commands::sync` に見せる。回線の変化と Google のログイン画面は小さな Swift のプラグイン (`src-tauri/plugins/ios`) が受け持つ。画面は `MobileMain` が Phase 0.5 のモバイル部品を、デスクトップと同じフックで実データにつなぐ。

**Tech Stack:** Rust 2024 (Tauri 2.12.3, tauri-build 2.7.2, tauri-plugin 2.7.1, tauri-plugin-notification 2.7.0, tauri-plugin-opener 2.7.1, keyring-core 1.0.1, apple-native-keyring-store 1.0.2 `protected`, objc2 0.6, objc2-foundation 0.3.2, time 0.3), Go (tailscale.com v1.104.1, cgo の c-archive), Swift (Tauri の iOS プラグイン、`NWPathMonitor`、`ASWebAuthenticationSession`)、React 19 + TypeScript、Storybook 10、Xcode 27、tauri-cli 2.12.2 (arm64、`~/.cargo/bin/cargo-tauri`)。

**Spec:** `docs/superpowers/specs/2026-10-20-phase6-ios-design.md` (以下「仕様」)。調査と試作: `docs/research/2026-10-19-ios-tailscale-research.md`、`docs/research/2026-10-19-ios-tailnet-spike.md`。試作のコードは手元のブランチ `spike/ios-tailnet` (worktree `.worktrees/ios-spike`) にある。読んで流用してよいが、試作用のもの (`commands/spike.rs`、`src/spike/`、`tlog!`、`POWERTODO_SPIKE_AUTOTEST`、`POWERTODO_IOS_NO_TAILNET`) は持ち込まない。

func TestProxyReopensOnTheSamePort(t *testing.T) {
	p := newProxyServer(dial(), "tsnet", "secret")
	first, err := p.Open()
	if err != nil { t.Fatal(err) }
	port := p.Port()
	p.Close()
	// The closed port refuses connections.
	if c, err := net.DialTimeout("tcp", fmt.Sprintf("127.0.0.1:%d", port), time.Second); err == nil {
		c.Close()
		t.Fatal("closed listener still accepts")
	}
	second, err := p.Open()
	if err != nil { t.Fatal(err) }
	if p.Port() != port || second != first {
		t.Fatalf("port %d -> %d, url %q -> %q", port, p.Port(), first, second)
	}
	p.Close()
}

func TestProxyFallsBackToANewPortWhenTheOldOneIsTaken(t *testing.T) {
	p := newProxyServer(dial(), "tsnet", "secret")
	if _, err := p.Open(); err != nil { t.Fatal(err) }
	port := p.Port()
	p.Close()
	squat, err := net.Listen("tcp", fmt.Sprintf("127.0.0.1:%d", port))
	if err != nil { t.Skip("port reused by someone else already") }
	defer squat.Close()
	if _, err := p.Open(); err != nil { t.Fatal(err) }
	if p.Port() == port { t.Fatal("expected a new port") }
	p.Close()
}

	p := newProxyServer(dial(), "tsnet", "secret")
