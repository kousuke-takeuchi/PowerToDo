# Phase 3 (繰り返し・リマインダー・通知・トレイ常駐) 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** タスクに繰り返し (RRULE) とリマインダーを持たせ、アプリがトレイに残っている間は OS 通知が届き、通知かアプリ内の帯から 完了 / 後で / 開く ができるようにする。

**Architecture:** RRULE の次回計算と自然言語変換、リマインダーの発火時刻は `domain` の純関数。`store` が完了時の期限送りと既定リマインダーの付与を行う。`scheduler` モジュールが 30 秒ごとに `due_reminders` (純関数) で判定し、`tauri-plugin-notification` で通知、`fired.json` に記録、UI にイベント。`tray.rs` がトレイとウィンドウの隠す / 出すを持つ。UI は Phase 2 の帯の仕組みにリマインダー帯を足す。最初に `Main.tsx` をフックに分ける。

**Tech Stack:** Rust 2024 (Tauri 2.12 + `tray-icon` feature, `rrule` 0.14, `tauri-plugin-notification` 2.6, chrono, serde), React 19 + TypeScript, motion 14.2, Storybook 10。

**Spec:** `docs/superpowers/specs/2026-10-15-phase3-time-design.md` (以下「仕様」)。全体設計 `2026-10-13-powertodo-overall-design.md`、Phase 1 / 2 の仕様も参照。

```rust
//! Recurrence (繰り返し) rules. The workbook stores the RRULE body only (`FREQ=WEEKLY;BYDAY=MO`);
//! `DTSTART` is built from the current due date at computation time (仕様 §3.1). A trailing
//! `;X-FROM=COMPLETED` marks completion-based repetition and is stripped before the `rrule` crate
//! sees the rule. Pure: no I/O, no clock.

use std::str::FromStr;

use chrono::{NaiveDate, NaiveDateTime, NaiveTime, TimeZone};
use rrule::{RRule, RRuleSet, Tz};

pub const FROM_COMPLETED: &str = "X-FROM=COMPLETED";

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Rule {
    pub core: String,
    pub from_completed: bool,
}

#[derive(Debug, thiserror::Error)]
pub enum RecurrenceError {
    #[error("繰り返しの指定が読めません: {0}")]
    Invalid(String),
}

pub fn split(rrule: &str) -> Rule {
    let mut from_completed = false;
    let parts: Vec<&str> = rrule
        .trim()
        .split(';')
        .map(str::trim)
        .filter(|p| !p.is_empty())
        .filter(|p| {
            if p.eq_ignore_ascii_case(FROM_COMPLETED) {
                from_completed = true;
                false
            } else {
                true
            }
        })
        .collect();
    Rule {
        core: parts.join(";"),
        from_completed,
    }
}

pub fn join(core: &str, from_completed: bool) -> String {
    if from_completed {
        format!("{core};{FROM_COMPLETED}")
    } else {
        core.to_string()
    }
}

fn dt_start(base: NaiveDate, due_time: Option<NaiveTime>) -> NaiveDateTime {
    base.and_time(due_time.unwrap_or(NaiveTime::MIN))
}

/// The first occurrence strictly after `DTSTART` (= `base` at `due_time`). `Ok(None)` when the
/// rule has no further occurrence (COUNT / UNTIL reached).
pub fn next_due(
    rrule: &str,
    due: Option<NaiveDate>,
    due_time: Option<NaiveTime>,
    base: NaiveDate,
) -> Result<Option<NaiveDate>, RecurrenceError> {
    let rule = split(rrule);
    if rule.core.is_empty() {
        return Err(RecurrenceError::Invalid(rrule.to_string()));
    }
    let start_day = if rule.from_completed { base } else { due.unwrap_or(base) };
    let start = Tz::LOCAL
        .from_local_datetime(&dt_start(start_day, due_time))
        .single()
        .ok_or_else(|| RecurrenceError::Invalid(rrule.to_string()))?;
    let parsed = RRule::from_str(&rule.core).map_err(|e| RecurrenceError::Invalid(format!("{rrule}: {e}")))?;
    let validated = parsed
        .validate(start)
        .map_err(|e| RecurrenceError::Invalid(format!("{rrule}: {e}")))?;
    let set = RRuleSet::new(start).rrule(validated);
    // `all` includes DTSTART itself when it matches the rule; take the first date strictly after it.
    let result = set.all(3);
    Ok(result
        .dates
        .into_iter()
        .find(|d| *d > start)
        .map(|d| d.date_naive()))
}

const WEEKDAYS: [(&str, &str); 7] = [
    ("MO", "月"),
    ("TU", "火"),
    ("WE", "水"),
    ("TH", "木"),
    ("FR", "金"),
    ("SA", "土"),
    ("SU", "日"),
];

fn params(core: &str) -> Vec<(String, String)> {
    core.split(';')
        .filter_map(|p| p.split_once('='))
        .map(|(k, v)| (k.to_ascii_uppercase(), v.to_ascii_uppercase()))
        .collect()
}

/// 表示用の短い要約 (仕様 §3.2 の表の逆方向)。表に無い形は `None`。
pub fn summarize(rrule: &str) -> Option<String> {
    let rule = split(rrule);
    let ps = params(&rule.core);
    let get = |k: &str| ps.iter().find(|(key, _)| key == k).map(|(_, v)| v.as_str());
    let known = ["FREQ", "INTERVAL", "BYDAY", "BYMONTHDAY", "BYMONTH"];
    if ps.iter().any(|(k, _)| !known.contains(&k.as_str())) {
        return None;
    }
    let freq = get("FREQ")?;
    let interval: u32 = get("INTERVAL").map(|v| v.parse().ok()).unwrap_or(Some(1))?;
    let suffix = if rule.from_completed { " (完了日から)" } else { "" };
    let body = match (freq, interval, get("BYDAY"), get("BYMONTHDAY"), get("BYMONTH")) {
        ("DAILY", 1, None, None, None) => "毎日".to_string(),
        ("DAILY", n, None, None, None) => format!("{n}日ごと"),
        ("WEEKLY", 1, Some("MO,TU,WE,TH,FR"), None, None) => "平日".to_string(),
        ("WEEKLY", 1, None, None, None) => "毎週".to_string(),
        ("WEEKLY", 2, None, None, None) => "隔週".to_string(),
        ("WEEKLY", 1, Some(days), None, None) => {
            let names: Option<Vec<&str>> = days
                .split(',')
                .map(|d| WEEKDAYS.iter().find(|(code, _)| *code == d).map(|(_, ja)| *ja))
                .collect();
            format!("毎週{}曜", names?.join("・"))
        }
        ("MONTHLY", 1, None, None, None) => "毎月".to_string(),
        ("MONTHLY", 1, None, Some("-1"), None) => "毎月末".to_string(),
        ("MONTHLY", 1, None, Some(day), None) => format!("毎月{}日", day.parse::<u32>().ok()?),
        ("YEARLY", 1, None, None, None) => "毎年".to_string(),
        ("YEARLY", 1, None, Some(day), Some(month)) => {
            format!("毎年{}月{}日", month.parse::<u32>().ok()?, day.parse::<u32>().ok()?)
        }
        _ => return None,
    };
    Some(format!("{body}{suffix}"))
}
```

```rust
//! Natural language → RRULE (仕様 §3.2). Japanese and English. Pure.

use super::recurrence::join;

const JA_DAYS: [(char, &str); 7] = [('月', "MO"), ('火', "TU"), ('水', "WE"), ('木', "TH"), ('金', "FR"), ('土', "SA"), ('日', "SU")];
const EN_DAYS: [(&str, &str); 7] = [
    ("mon", "MO"),
    ("tue", "TU"),
    ("wed", "WE"),
    ("thu", "TH"),
    ("fri", "FR"),
    ("sat", "SA"),
    ("sun", "SU"),
];
const EN_MONTHS: [&str; 12] = ["jan", "feb", "mar", "apr", "may", "jun", "jul", "aug", "sep", "oct", "nov", "dec"];

/// Full-width digits → ASCII; everything else unchanged.
fn ascii_digits(s: &str) -> String {
    s.chars()
        .map(|c| match c {
            '０'..='９' => char::from_u32(c as u32 - '０' as u32 + '0' as u32).unwrap_or(c),
            _ => c,
        })
        .collect()
}

/// Strips a trailing `!` / `！` (completion-based marker). Returns (word, from_completed).
fn bang(word: &str) -> (&str, bool) {
    if let Some(w) = word.strip_suffix('!').or_else(|| word.strip_suffix('！')) {
        (w, true)
    } else {
        (word, false)
    }
}

/// `月水金` → `MO,WE,FR`; `月曜` / `月曜日` also accepted. None when any char is not a weekday.
fn ja_weekdays(s: &str) -> Option<String> {
    let s = s.trim_end_matches('日').trim_end_matches('曜');
    // 「日曜」 was reduced to "" above when the day is 日; handle it before the loop.
    if s.is_empty() {
        return None;
    }
    let codes: Option<Vec<&str>> = s
        .chars()
        .map(|c| JA_DAYS.iter().find(|(ja, _)| *ja == c).map(|(_, code)| *code))
        .collect();
    codes.map(|c| c.join(","))
}

fn ja_weekdays_or_sunday(s: &str) -> Option<String> {
    if matches!(s, "日曜" | "日曜日") {
        return Some("SU".into());
    }
    ja_weekdays(s)
}

/// `mon,wed,fri` / `monday` → `MO,WE,FR`.
fn en_weekdays(s: &str) -> Option<String> {
    let codes: Option<Vec<&str>> = s
        .split(',')
        .map(|d| {
            let d = d.trim().to_ascii_lowercase();
            EN_DAYS.iter().find(|(name, _)| d.starts_with(name)).map(|(_, code)| *code)
        })
        .collect();
    codes.filter(|c| !c.is_empty()).map(|c| c.join(","))
}

fn number(s: &str) -> Option<u32> {
    let s = s.trim_end_matches("st").trim_end_matches("nd").trim_end_matches("rd").trim_end_matches("th");
    s.parse().ok().filter(|n| *n > 0)
}

/// One Japanese word (no spaces inside). Returns the RRULE body (without the completion marker).
fn ja_single(word: &str) -> Option<String> {
    let w = ascii_digits(word);
    let w = w.as_str();
    Some(match w {
        "毎日" => "FREQ=DAILY".into(),
        "平日" => "FREQ=WEEKLY;BYDAY=MO,TU,WE,TH,FR".into(),
        "毎週" => "FREQ=WEEKLY".into(),
        "隔週" => "FREQ=WEEKLY;INTERVAL=2".into(),
        "毎月" => "FREQ=MONTHLY".into(),
        "毎月末" | "月末" => "FREQ=MONTHLY;BYMONTHDAY=-1".into(),
        "毎年" => "FREQ=YEARLY".into(),
        _ => {
            if let Some(days) = w.strip_prefix("毎週") {
                return ja_weekdays_or_sunday(days).map(|d| format!("FREQ=WEEKLY;BYDAY={d}"));
            }
            if let Some(rest) = w.strip_prefix("毎年") {
                // 10月18日
                let (m, d) = rest.split_once('月')?;
                let d = d.strip_suffix('日')?;
                return Some(format!("FREQ=YEARLY;BYMONTH={};BYMONTHDAY={}", number(m)?, number(d)?));
            }
            if let Some(rest) = w.strip_prefix("毎月") {
                let d = rest.strip_suffix('日')?;
                return Some(format!("FREQ=MONTHLY;BYMONTHDAY={}", number(d)?));
            }
            if let Some(n) = w.strip_suffix("日ごと").or_else(|| w.strip_suffix("日毎")) {
                return Some(format!("FREQ=DAILY;INTERVAL={}", number(n)?));
            }
            if let Some(rest) = w.strip_prefix('毎') {
                // 毎3日 (Todoist style)
                let n = rest.strip_suffix('日')?;
                return Some(format!("FREQ=DAILY;INTERVAL={}", number(n)?));
            }
            return None;
        }
    })
}

/// Tries to read a recurrence starting at `words[0]`. Returns the RRULE and the number of words used.
pub fn parse_recurrence(words: &[&str]) -> Option<(String, usize)> {
    let first = *words.first()?;
    let lower = first.to_ascii_lowercase();

    // ---- Japanese: one word, or 毎週 / 毎月 + a second word ----
    {
        let (w, from_completed) = bang(first);
        if let Some(core) = ja_single(w) {
            return Some((join(&core, from_completed), 1));
        }
        if w == "毎週" && let Some(next) = words.get(1) && let Some(days) = ja_weekdays_or_sunday(next) {
            return Some((format!("FREQ=WEEKLY;BYDAY={days}"), 2));
        }
        if w == "毎月" && let Some(next) = words.get(1) {
            // 毎月 15 日  /  毎月 15日
            let n = ascii_digits(next);
            if let Some(d) = n.strip_suffix('日').and_then(number) {
                return Some((format!("FREQ=MONTHLY;BYMONTHDAY={d}"), 2));
            }
            if let Some(d) = number(&n) && words.get(2).is_some_and(|w| *w == "日") {
                return Some((format!("FREQ=MONTHLY;BYMONTHDAY={d}"), 3));
            }
        }
    }

    // ---- English single words ----
    let (lw, from_completed) = bang(lower.as_str());
    match lw {
        "daily" => return Some((join("FREQ=DAILY", from_completed), 1)),
        "weekdays" => return Some(("FREQ=WEEKLY;BYDAY=MO,TU,WE,TH,FR".into(), 1)),
        "weekly" => return Some(("FREQ=WEEKLY".into(), 1)),
        "monthly" => {
            // monthly on 15
            if words.get(1).is_some_and(|w| w.eq_ignore_ascii_case("on")) && let Some(d) = words.get(2).and_then(|w| number(w)) {
                return Some((format!("FREQ=MONTHLY;BYMONTHDAY={d}"), 3));
            }
            return Some(("FREQ=MONTHLY".into(), 1));
        }
        "yearly" => return Some(("FREQ=YEARLY".into(), 1)),
        _ => {}
    }
    if lw == "last" && words.len() >= 4 && words[1].eq_ignore_ascii_case("day") && words[2].eq_ignore_ascii_case("of") && words[3].eq_ignore_ascii_case("month") {
        return Some(("FREQ=MONTHLY;BYMONTHDAY=-1".into(), 4));
    }
    if lw != "every" {
        return None;
    }
    let second = words.get(1)?;
    let (s, from_completed) = bang(&second.to_ascii_lowercase());
    match s {
        "day" => return Some((join("FREQ=DAILY", from_completed), 2)),
        "weekday" => return Some(("FREQ=WEEKLY;BYDAY=MO,TU,WE,TH,FR".into(), 2)),
        "week" => return Some(("FREQ=WEEKLY".into(), 2)),
        "other" => {
            if words.get(2).is_some_and(|w| w.eq_ignore_ascii_case("week")) {
                return Some(("FREQ=WEEKLY;INTERVAL=2".into(), 3));
            }
            return None;
        }
        "month" => {
            if words.get(2).is_some_and(|w| w.eq_ignore_ascii_case("end")) {
                return Some(("FREQ=MONTHLY;BYMONTHDAY=-1".into(), 3));
            }
            // every month on the 1st
            if words.get(2).is_some_and(|w| w.eq_ignore_ascii_case("on")) {
                let mut i = 3;
                if words.get(i).is_some_and(|w| w.eq_ignore_ascii_case("the")) {
                    i += 1;
                }
                if let Some(d) = words.get(i).and_then(|w| number(&w.to_ascii_lowercase())) {
                    return Some((format!("FREQ=MONTHLY;BYMONTHDAY={d}"), i + 1));
                }
            }
            return Some(("FREQ=MONTHLY".into(), 2));
        }
        "year" => return Some(("FREQ=YEARLY".into(), 2)),
        _ => {}
    }
    if let Some(days) = en_weekdays(s) {
        return Some((format!("FREQ=WEEKLY;BYDAY={days}"), 2));
    }
    if let Some(month) = EN_MONTHS.iter().position(|m| s.starts_with(m)) && let Some(d) = words.get(2).and_then(|w| number(&w.to_ascii_lowercase())) {
        return Some((format!("FREQ=YEARLY;BYMONTH={};BYMONTHDAY={d}", month + 1), 3));
    }
    // every 3 days / every 2 weeks (optionally with a trailing !)
    if let Some(n) = number(s) && let Some(unit) = words.get(2) {
        let (unit, from_completed) = bang(&unit.to_ascii_lowercase());
        return match unit {
            "day" | "days" => Some((join(&format!("FREQ=DAILY;INTERVAL={n}"), from_completed), 3)),
            "week" | "weeks" => Some((join(&format!("FREQ=WEEKLY;INTERVAL={n}"), from_completed), 3)),
            "month" | "months" => Some((join(&format!("FREQ=MONTHLY;INTERVAL={n}"), from_completed), 3)),
            _ => None,
        };
    }
    None
}

/// Whole text (the picker's input). Some only when every word belongs to the recurrence.
pub fn parse_recurrence_text(text: &str) -> Option<String> {
    let words: Vec<&str> = text.split_whitespace().collect();
    let (rrule, used) = parse_recurrence(&words)?;
    (used == words.len()).then_some(rrule)
}
```

```rust
//! Reminder codes (リマインダー列) and when they fire (仕様 §4.1). Pure.

use chrono::{Days, Duration, NaiveDate, NaiveDateTime, NaiveTime};

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Reminder {
    /// `-0m`, `-10m`, `-30m`, `-60m`: minutes before the due time.
    Before(Duration),
    /// `-1d`: the day before, at the configured notify time.
    DayBefore,
    /// `-1w`: a week before, at the configured notify time.
    WeekBefore,
    /// `YYYY-MM-DDTHH:MM`: a fixed local time.
    At(NaiveDateTime),
}

const BEFORE_MINUTES: [i64; 4] = [0, 10, 30, 60];

pub fn parse_code(code: &str) -> Option<Reminder> {
    match code.trim() {
        "-1d" => Some(Reminder::DayBefore),
        "-1w" => Some(Reminder::WeekBefore),
        c if c.starts_with('-') && c.ends_with('m') => {
            let n: i64 = c[1..c.len() - 1].parse().ok()?;
            BEFORE_MINUTES.contains(&n).then(|| Reminder::Before(Duration::minutes(n)))
        }
        c => NaiveDateTime::parse_from_str(c, "%Y-%m-%dT%H:%M").ok().map(Reminder::At),
    }
}

pub fn code_of(r: &Reminder) -> String {
    match r {
        Reminder::Before(d) => format!("-{}m", d.num_minutes()),
        Reminder::DayBefore => "-1d".into(),
        Reminder::WeekBefore => "-1w".into(),
        Reminder::At(t) => t.format("%Y-%m-%dT%H:%M").to_string(),
    }
}

pub fn is_absolute(code: &str) -> bool {
    matches!(parse_code(code), Some(Reminder::At(_)))
}

pub fn fire_time(
    code: &str,
    due: Option<NaiveDate>,
    due_time: Option<NaiveTime>,
    notify_time: NaiveTime,
) -> Option<NaiveDateTime> {
    match parse_code(code)? {
        Reminder::At(t) => Some(t),
        Reminder::Before(d) => Some(due?.and_time(due_time?) - d),
        Reminder::DayBefore => Some(due?.checked_sub_days(Days::new(1))?.and_time(notify_time)),
        Reminder::WeekBefore => Some(due?.checked_sub_days(Days::new(7))?.and_time(notify_time)),
    }
}
```

```rust
    pub fn complete_task(&mut self, project: &str, no: u32, done: bool) -> AppResult<ProjectView> {
        let mut warning: Option<String> = None;
        self.mutate(project, |book, ctx| {
            let idx = find_task(book, no)?;
            let t = &mut book.tasks[idx];
            if !done {
                t.progress = 0;
                t.completed_at = None;
                return Ok(());
            }
            let today = ctx.now.date();
            if let Some(rrule) = t.rrule.clone() {
                let rule = recurrence::split(&rrule);
                let base = if rule.from_completed { today } else { t.due.unwrap_or(today) };
                match recurrence::next_due(&rrule, t.due, t.due_time, base) {
                    Ok(Some(next)) => {
                        t.due = Some(next);
                        t.progress = 0;
                        t.completed_at = None;
                        t.reminders.retain(|c| !reminders::is_absolute(c));
                        return Ok(());
                    }
                    Ok(None) => t.rrule = None,
                    Err(e) => warning = Some(e.to_string()),
                }
            }
            if t.progress != 100 {
                t.completed_at = None;
            }
            t.progress = 100;
            t.completed_at.get_or_insert(ctx.now);
            Ok(())
        })?;
        let mut view = self.view(project)?;
        view.warnings.extend(warning);
        Ok(view)
    }
```

```rust
pub struct Decision { pub fire: Vec<ReminderItem>, pub missed: Vec<ReminderItem> }

pub fn due_reminders(tasks: &[Task], fired: &Fired, now: NaiveDateTime, settings: &Settings) -> Decision {
    let mut fire = Vec::new();
    let mut missed = Vec::new();
    for t in tasks.iter().filter(|t| t.progress < 100) {
        for code in &t.reminders {
            let key = ReminderKey { project: t.project.clone(), no: t.no, code: code.clone() };
            let at = match fired.snooze_until(&key) {
                Some(until) => until,
                None => match reminders::fire_time(code, t.due, t.due_time, settings.notify_time) {
                    Some(at) => at,
                    None => continue,
                },
            };
            if at > now || fired.contains(&key, at) {
                continue;
            }
            let item = ReminderItem { project: t.project.clone(), no: t.no, title: t.title.clone(), code: code.clone(), at, due: t.due, due_time: t.due_time };
            if now - at <= Duration::hours(24) { fire.push(item) } else { missed.push(item) }
        }
    }
    Decision { fire, missed }
}
```
