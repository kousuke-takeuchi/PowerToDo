# Drag (③) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Drag tasks, sections and projects the Todoist way:
- reorder, indent by horizontal movement, drop onto a row to make it a subtask, move across sections;
- reorder sections and projects;
- drop a task on a sidebar project to move it;
- drop on an Upcoming day to reschedule;
- a Today-only order;
- the same moves from the keyboard.

**Architecture:**
- **Rust store:**
  - `move_within` places a task (with its subtree) under a new section / parent / position, renumbering the new siblings.
  - `reorder_projects` writes the project order in the common book.
  - The Today order lives in the task's unknown-column map (`extra["今日の並び"]`, value `YYYY-MM-DD:n`). It needs no new known column, old versions keep it, and it merges per field. `today_view` sorts by it, and the task-level merge does not count it as an edit.
- **Frontend:** one hand-written drag engine.
  - Pointer events on handles start a drag.
  - A portal layer draws the lifted card and the red line.
  - Drop targets are found from DOM data attributes. The drop computation over measured row boxes is a pure, tested function.
  - Main receives the result through a `DragActions` context and saves it.

**Tech Stack:** Rust (store, Tauri commands), React 19, TypeScript, motion, Storybook 10, Pencil MCP for `design.pen`.

**Spec:** `docs/superpowers/specs/2026-10-25-drag-design.md` (PR #55). Research: `docs/research/2026-10-25-todoist-drag.md`.

**Prerequisite:** Merge #55 (spec) and this plan's PR first. Start `feature/drag` from origin/main after that. Copy `src-tauri/binaries/powertodo-tailnet-aarch64-apple-darwin` from another worktree into the new one (it is git-ignored and the build needs it).

## Global Constraints

- Desktop only. `MobileMain`, `src/views/mobile/*` and `variant="mobile"` rows are unchanged.
- No new npm dependency (no drag library).
- Numbers:
  - Lift after 4 px of movement.
  - One indent level is 28 px. The level changes past a half step (14 px).
  - Deepest level 2 (three levels: 0, 1, 2).
  - Onto-row zone: the middle half of a row (top and bottom quarters excluded).
  - Autoscroll zone: 48 px; at most 16 px per frame.
  - The original row stays at opacity 0.4.
  - The settle motion is about 0.15 s through `useMotionTiming()`.
- Look:
  - Card: `var(--color-bg)`, radius 6, `var(--shadow-popover)`.
  - Red line: 2 px `var(--color-accent)`, with an 8 px ring at its left end, starting at level × 28.
  - Onto-row: a 1 px `var(--color-accent)` ring, radius 6.
  - Sidebar project / Upcoming day highlight: `var(--color-accent-soft)` background.
- The Today order column name is exactly `今日の並び`. Its value is `YYYY-MM-DD:n` (n from 1). A value whose date is not today counts as absent.
- Keys on the focused row:
  - ⌥↑ / ⌥↓ move within siblings.
  - Ctrl+] indents; Ctrl+[ outdents.
  - All keys are off while an editor, menu or dialog is open, or while typing.
- Toast copy:
  - 「タスクを <project> に移しました」 + 「開く」;
  - 「日付を <label> に更新しました」 + 「元に戻す」 (as ②).
- `design.pen`: the owner opens the worktree copy (check `mcp__pencil__get_app_state`) and saves it with ⌘S.
- Never print or commit `src-tauri/google-oauth.json` / `google-oauth-ios.plist`. No `-v` builds. Do not run the real app.
- Commit messages have no `Co-Authored-By` or AI trailer.

## Rulings already taken in this plan (against the spec)

- **The Today order column.** Spec §6.2 says "a new column after R" and §8 says `today_order: Option<String>`. This plan stores it in `Task.extra` under the key `今日の並び` instead. The book writer already appends unknown columns after R and keeps them, the sync merges `extra` per field, and old app versions keep the column. Same file result, no change to the 18 known columns.
- **Upcoming and today drops** need no new commands: a day drop is `update_task { due }`; the Today order is `set_today_order`.

## Review Focus

1. **Dropping a parent between its own subtasks**, or onto one of them, must be impossible: no line and no ring there, and releasing does nothing. Test: `computeDrop` excludes the dragged subtree (Task 2) and `move_within_into_own_subtree_is_refused` (Task 1).
2. **Dropping into an empty section** (its only row is 「タスクを追加」) must put the task in that section. Test: `computeDrop` gap before a `slot` row (Task 2).
3. **Indenting a task that has subtasks past the depth limit** must stop at the deepest allowed level. Test: `computeDrop` caps the level by the subtree height (Task 2) and `move_within_beyond_depth_is_refused` (Task 1).
4. **A drag released outside every target** (over the top bar, outside the window) must cancel with nothing saved. Test: `computeDrop` returns null outside the rows (Task 2); the engine treats null as cancel (Task 3).
5. **A Today-order value from yesterday** must not sort a task to the top today. Test: `today_view_ignores_an_old_today_order` (Task 1).

```rust
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]

    pub section: Option<String>,
    pub parent: Option<u32>,
    pub before: Option<u32>,
}

/// The unknown column that holds the Today-only order (spec ③ §6.2): `YYYY-MM-DD:n`.

/// `n` of a `今日の並び` value written for `today`, else None.
pub fn today_rank(value: Option<&String>, today: NaiveDate) -> Option<u32> {
    let (date, n) = value?.split_once(':')?;
    (NaiveDate::parse_from_str(date, "%Y-%m-%d").ok()? == today).then(|| n.parse().ok()).flatten()
}
```

```rust
    /// Spec ③ §8: moves the task and its subtree to `to` in the same project. The new siblings
    /// are numbered 1, 2, ... in their shown order (only 並び順 changes for them); the subtree
    /// takes the new section. The parent must not be in the subtree, must sit in that section,
    /// and the subtree must stay within three levels.
    pub fn move_within(&mut self, project: &str, no: u32, to: Placement) -> AppResult<ProjectView> {
        let section = to.section.as_deref().and_then(non_empty);
        self.mutate(project, |book, _| {
            if let Some(s) = &section {
                check_section(book, s)?;
            }
            find_task(book, no)?;
            let moved: BTreeSet<u32> = subtree(book, no).into_iter().map(|i| book.tasks[i].no).collect();
            let depth_of = |book: &ProjectBook, mut n: u32| {
                let mut d = 0;
                while let Some(p) = book.tasks.iter().find(|t| t.no == n).and_then(|t| t.parent_no) {
                    d += 1;
                    n = p;
                }
                d
            };
            let height = moved
                .iter()
                .map(|&n| depth_of(book, n) - depth_of(book, no))
                .max()
                .unwrap_or(0);
            if let Some(p) = to.parent {
                if moved.contains(&p) {
                    return Err(invalid("自分のサブタスクの下には動かせません"));
                }
                let parent = &book.tasks[find_task(book, p)?];
                if parent.category != section {
                    return Err(invalid("親と同じセクションにしか動かせません"));
                }
                if depth_of(book, p) + 1 + height > 2 {
                    return Err(invalid("これ以上深くできません (3 段まで)"));
                }
            }
            for i in subtree(book, no) {
                book.tasks[i].category = section.clone();
            }
            let i = find_task(book, no)?;
            book.tasks[i].parent_no = to.parent;
            let mut sibs: Vec<usize> = (0..book.tasks.len())
                .filter(|&k| k != i && book.tasks[k].category == section && book.tasks[k].parent_no == to.parent)
                .collect();
            sibs.sort_by_key(|&k| (book.tasks[k].order, k));
            let at = match to.before {
                Some(b) => sibs
                    .iter()
                    .position(|&k| book.tasks[k].no == b)
                    .ok_or_else(|| invalid("位置のタスクが同じ並びにありません"))?,
                None => sibs.len(),
            };
            sibs.insert(at, i);
            for (n, &k) in sibs.iter().enumerate() {
                book.tasks[k].order = u32::try_from(n + 1).unwrap_or(u32::MAX);
            }
            Ok(())
        })?;
        self.view(project)
    }

    /// Spec ③ §4.1: the projects in this order after the inbox (which stays first). Projects
    /// not listed keep their relative order after the listed ones.
    pub fn reorder_projects(&mut self, names: &[String]) -> AppResult<Vec<ProjectSummary>> {
        for n in names {
            if !self.common.projects.iter().any(|p| &p.name == n) {
                return Err(not_found(format!("プロジェクト「{n}」が見つかりません")));
            }
        }
        let mut rest: Vec<String> = self.summaries().into_iter().map(|s| s.name).filter(|n| n != INBOX && !names.contains(n)).collect();
        let mut ordered: Vec<String> = names.iter().filter(|n| n.as_str() != INBOX).cloned().collect();
        ordered.append(&mut rest);
        for p in self.common.projects.iter_mut() {
            p.order = if p.inbox { 0 } else { ordered.iter().position(|n| n == &p.name).map_or(u32::MAX, |i| i as u32 + 1) };
        }
        self.common_dirty = true;
        Ok(self.summaries())
    }

    /// Spec ③ §6.2: writes `<today>:<n>` into each task's 今日の並び, in this order. Returns the
    /// projects it changed (to save).
    pub fn set_today_order(&mut self, today: NaiveDate, keys: &[(String, u32)]) -> AppResult<Vec<String>> {
        let mut by_project: BTreeMap<String, Vec<(u32, usize)>> = BTreeMap::new();
        for (i, (p, no)) in keys.iter().enumerate() {
            by_project.entry(p.clone()).or_default().push((*no, i + 1));
        }
        let stamp = today.format("%Y-%m-%d").to_string();
        for (p, list) in &by_project {
            self.mutate(p, |book, _| {
                for (no, n) in list {
                    let i = find_task(book, *no)?;
                    book.tasks[i].extra.insert(TODAY_ORDER.to_string(), format!("{stamp}:{n}"));
                }
                Ok(())
            })?;
        }
        Ok(by_project.into_keys().collect())
    }
```

```ts
import type { Placement } from "../../types/model";

export type RowBox =
  | { kind: "task"; key: string; no: number; depth: number; parent: number | null; section: string | null; top: number; bottom: number }
  | { kind: "header"; section: string; top: number; bottom: number }
  | { kind: "slot"; section: string | null; top: number; bottom: number };
export type Drop = { kind: "between"; index: number; depth: number; y: number; x: number } | { kind: "onto"; key: string };

export const LEVEL = 28;
const MAX_DEPTH = 2;
const EDGE = 48;
const MAX_SPEED = 16;

type Dragged = { key: string; depth: number; height: number; subtree: Set<string> };
const isTask = (r: RowBox | undefined): r is Extract<RowBox, { kind: "task" }> => r?.kind === "task";

/**
 * Spec ③ §3.1–§3.3. `rows` are the shown rows top to bottom (page coordinates), `startX` where the drag began,
 * `left` the x of level 0. Null: no place (outside the rows, or only the dragged subtree there).
 */
export function computeDrop(rows: RowBox[], p: { x: number; y: number }, startX: number, d: Dragged, left: number): Drop | null {
  const i = rows.findIndex((r) => p.y >= r.top && p.y < r.bottom);
  if (i < 0) return null;
  const r = rows[i];
  const quarter = (r.bottom - r.top) / 4;
  if (isTask(r) && d.subtree.has(r.key)) return null;
  if (isTask(r) && p.y >= r.top + quarter && p.y < r.bottom - quarter && r.depth + 1 + d.height <= MAX_DEPTH) return { kind: "onto", key: r.key };
  // The gap above or below this row (a header's gap is always below it, a slot's above it).
  const below = r.kind === "header" || (r.kind === "task" && p.y >= (r.top + r.bottom) / 2);
  let index = below ? i + 1 : i;
  // Skip the dragged subtree: the gap moves past it.
  while (isTask(rows[index]) && d.subtree.has((rows[index] as { key: string }).key)) index++;
  let prevIdx = index - 1;
  while (prevIdx >= 0 && isTask(rows[prevIdx]) && d.subtree.has((rows[prevIdx] as { key: string }).key)) prevIdx--;
  const prev = rows[prevIdx];
  const next = rows[index];
  const maxBy = isTask(prev) ? prev.depth + 1 : 0;
  const max = Math.max(0, Math.min(maxBy, MAX_DEPTH - d.height));
  const min = Math.min(isTask(next) ? next.depth : 0, max);
  const wanted = d.depth + Math.round((p.x - startX) / LEVEL);
  const depth = Math.max(min, Math.min(max, wanted));
  const y = next ? next.top : (prev?.bottom ?? r.bottom);
  return { kind: "between", index, depth, y, x: left + depth * LEVEL };
}

/** The store placement of a drop (spec ③ §8). Null when it would not move anything. */
export function placementOf(rows: RowBox[], drop: Drop, draggedKey: string): Placement | null {
  if (drop.kind === "onto") {
    const r = rows.find((x) => isTask(x) && x.key === drop.key) as Extract<RowBox, { kind: "task" }> | undefined;
    return r ? { section: r.section, parent: r.no, before: null } : null;
  }
  const { index, depth } = drop;
  // Section: of the nearest row above (a header starts its section), else unsectioned.
  let section: string | null = null;
  for (let k = index - 1; k >= 0; k--) {
    const r = rows[k];
    if (r.kind === "header") { section = r.section; break; }
    if (r.kind === "task" || r.kind === "slot") { section = r.section; break; }
  }
  // Parent: the nearest task above at depth - 1 (stopping at the section start).
  let parent: number | null = null;
  if (depth > 0) {
    for (let k = index - 1; k >= 0; k--) {
      const r = rows[k];
      if (r.kind !== "task") break;
      if (r.key === draggedKey) continue;
      if (r.depth === depth - 1) { parent = r.no; break; }
    }
    if (parent === null) return null;
  }
  // Before: the first following task at this depth with this parent, before the level ends.
  let before: number | null = null;
  for (let k = index; k < rows.length; k++) {
    const r = rows[k];
    if (r.kind !== "task") break;
    if (r.key === draggedKey) continue;
    if (r.depth < depth) break;
    if (r.depth === depth && r.parent === parent) { before = r.no; break; }
  }
  return { section, parent, before };
}

/** Pixels per frame to scroll: negative near the top edge, positive near the bottom (spec ③ §2.3). */
export function autoScrollSpeed(y: number, top: number, bottom: number): number {
  if (y < top + EDGE) return -Math.round(MAX_SPEED * Math.min(1, (top + EDGE - y) / EDGE));
  if (y > bottom - EDGE) return Math.round(MAX_SPEED * Math.min(1, (y - (bottom - EDGE)) / EDGE));
  return 0;
}
```

```ts
import type { Placement, Task } from "../../types/model";

const siblingsOf = (tasks: Task[], t: Task) =>
  tasks.filter((x) => x.category === t.category && x.parentNo === t.parentNo).sort((a, b) => a.order - b.order || a.no - b.no);
const at = (t: Task, before: number | null, parent = t.parentNo ?? null): Placement => ({ section: t.category, parent, before });
const depthOf = (tasks: Task[], t: Task): number => (t.parentNo === undefined ? 0 : 1 + depthOf(tasks, tasks.find((x) => x.no === t.parentNo)!));
const heightOf = (tasks: Task[], no: number): number =>
  Math.max(0, ...tasks.filter((x) => x.parentNo === no).map((c) => 1 + heightOf(tasks, c.no)));

/** ⌥↑ / ⌥↓ (spec ③ §7): one place up / down among the siblings. Null at the ends. */
export function siblingMove(tasks: Task[], no: number, dir: -1 | 1): Placement | null {
  const t = tasks.find((x) => x.no === no);
  if (!t) return null;
  const s = siblingsOf(tasks, t);
  const i = s.findIndex((x) => x.no === no);
  const j = i + dir;
  if (j < 0 || j >= s.length) return null;
  // Up: before the one above. Down: before the one after the next (or at the end).
  return at(t, dir < 0 ? s[j].no : (s[j + 1]?.no ?? null));
}

/** Ctrl+] : the last subtask of the sibling above. Null at the top or past three levels. */
export function indentMove(tasks: Task[], no: number): Placement | null {
  const t = tasks.find((x) => x.no === no);
  if (!t) return null;
  const s = siblingsOf(tasks, t);
  const above = s[s.findIndex((x) => x.no === no) - 1];
  if (!above || depthOf(tasks, above) + 1 + heightOf(tasks, no) > 2) return null;
  return at(t, null, above.no);
}

/** Ctrl+[ : right after the parent, among the parent's siblings. Null at the top level. */
export function outdentMove(tasks: Task[], no: number): Placement | null {
  const t = tasks.find((x) => x.no === no);
  const parent = t && tasks.find((x) => x.no === t.parentNo);
  if (!t || !parent) return null;
  const s = siblingsOf(tasks, parent);
  const next = s[s.findIndex((x) => x.no === parent.no) + 1];
  return at(parent, next?.no ?? null, parent.parentNo ?? null);
}
```

The DOM contract (later tasks put these attributes on their elements):
- A task drop list: `data-drop-list="project"` or `"today"`, on the element that holds the rows.
- Each row box inside it: `data-row` with one of:
  - `data-row-kind="task"` plus `data-key`, `data-no`, `data-depth`, `data-parent` (number or empty), `data-section` (name or empty);
  - `data-row-kind="header"` plus `data-section`;
  - `data-row-kind="slot"` plus `data-section`.
- `data-level0`: on the drop list element, the x (px, relative to the list's left) of level 0.
- Sidebar project items: `data-drop-project="<name>"`.
- Upcoming day sections: `data-drop-day="YYYY-MM-DD"`.
- Section headers in a project: `data-drop-section="<name>"`. Their list is the element with `data-section-list`.
- Sidebar project list: `data-project-list`, items `data-project-item="<name>"`.

```tsx
import type React from "react";
import { createContext, useCallback, useEffect, useRef, useState } from "react";
import { createPortal } from "react-dom";
import type { Placement, Task } from "../../types/model";
import { autoScrollSpeed, computeDrop, placementOf, type Drop, type RowBox } from "./dropTarget";

export type DragSource =
  | { kind: "task"; task: Task; view: "project" | "today" | "upcoming" | "label"; depth: number; height: number; subtree: Set<string> }
  | { kind: "section"; project: string; name: string }
  | { kind: "project"; name: string };
type TaskSource = Extract<DragSource, { kind: "task" }>;
export type DropResult =
  | { kind: "place"; source: TaskSource; placement: Placement }
  | { kind: "today"; source: TaskSource; beforeKey: string | null }
  | { kind: "day"; source: TaskSource; date: string }
  | { kind: "project"; source: TaskSource; project: string }
  | { kind: "sections"; project: string; names: string[] }
  | { kind: "projects"; names: string[] };
export type DragApi = { start: (e: React.PointerEvent, source: DragSource, card: React.ReactNode) => void; active: DragSource | null };

export const DragCtx = createContext<DragApi | null>(null);

const LIFT = 4;
type Target =
  | { kind: "list"; drop: Drop; rows: RowBox[]; list: "project" | "today" }
  | { kind: "project"; name: string; rect: DOMRect }
  | { kind: "day"; date: string; rect: DOMRect }
  | { kind: "order"; attr: "section" | "project"; names: string[]; index: number; y: number; x: number; w: number };

function rowBoxes(list: Element): RowBox[] {
  return [...list.querySelectorAll<HTMLElement>("[data-row]")].map((el) => {
    const r = el.getBoundingClientRect();
    const d = el.dataset;
    const section = d.section ? d.section : null;
    if (d.rowKind === "header") return { kind: "header", section: d.section ?? "", top: r.top, bottom: r.bottom };
    if (d.rowKind === "slot") return { kind: "slot", section, top: r.top, bottom: r.bottom };
    return { kind: "task", key: d.key!, no: Number(d.no), depth: Number(d.depth), parent: d.parent ? Number(d.parent) : null, section, top: r.top, bottom: r.bottom };
  });
}

/** Spec ③ §2: lift after 4 px, a card follows the pointer, a red line (or a ring / highlight) shows the target. */
export function DragProvider({ onDrop, children }: { onDrop: (r: DropResult) => void; children: React.ReactNode }) {
  const [active, setActive] = useState<DragSource | null>(null);
  const [card, setCard] = useState<{ node: React.ReactNode; x: number; y: number; dx: number; dy: number; w: number } | null>(null);
  const [target, setTarget] = useState<Target | null>(null);
  const drag = useRef<{ source: DragSource; sx: number; sy: number; lifted: boolean; node: React.ReactNode; rect: DOMRect; key?: string } | null>(null);
  const targetRef = useRef<Target | null>(null);
  const pointer = useRef({ x: 0, y: 0 });
  const onDropRef = useRef(onDrop);
  onDropRef.current = onDrop;

  const find = useCallback((x: number, y: number): Target | null => {
    const d = drag.current;
    if (!d) return null;
    const el = document.elementFromPoint(x, y);
    if (!el) return null;
    if (d.source.kind === "task") {
      const proj = el.closest<HTMLElement>("[data-drop-project]");
      if (proj) return { kind: "project", name: proj.dataset.dropProject!, rect: proj.getBoundingClientRect() };
      const day = el.closest<HTMLElement>("[data-drop-day]");
      if (day && d.source.view === "upcoming") return { kind: "day", date: day.dataset.dropDay!, rect: day.getBoundingClientRect() };
      const list = el.closest<HTMLElement>("[data-drop-list]");
      const kind = list?.dataset.dropList as "project" | "today" | undefined;
      if (list && kind && (kind === d.source.view)) {
        const rows = rowBoxes(list);
        const left = list.getBoundingClientRect().left + Number(list.dataset.level0 ?? 0);
        const s = d.source;
        const dragged = kind === "today" ? { key: d.key!, depth: 0, height: 2, subtree: s.subtree } : { key: d.key!, depth: s.depth, height: s.height, subtree: s.subtree };
        const drop = computeDrop(rows, { x, y }, d.sx, dragged, left);
        return drop ? { kind: "list", drop, rows, list: kind } : null;
      }
      return null;
    }
    // Sections / projects: a line between items of the same list.
    const attr = d.source.kind === "section" ? "section" : "project";
    const listEl = document.querySelector(d.source.kind === "section" ? "[data-section-list]" : "[data-project-list]");
    if (!listEl) return null;
    const items = [...listEl.querySelectorAll<HTMLElement>(attr === "section" ? "[data-drop-section]" : "[data-project-item]")];
    const names = items.map((it) => (attr === "section" ? it.dataset.dropSection! : it.dataset.projectItem!));
    const rects = items.map((it) => it.getBoundingClientRect());
    if (!rects.length) return null;
    const lr = listEl.getBoundingClientRect();
    if (x < lr.left || x > lr.right) return null;
    let index = rects.findIndex((r) => y < (r.top + r.bottom) / 2);
    if (index < 0) index = rects.length;
    const yLine = index < rects.length ? rects[index].top : rects[rects.length - 1].bottom;
    return { kind: "order", attr, names, index, y: yLine, x: lr.left, w: lr.width };
  }, []);

  useEffect(() => {
    if (!active) return;
    let raf = 0;
    const tick = () => {
      const scroller = document.querySelector<HTMLElement>("[data-drag-scroll]");
      if (scroller) {
        const r = scroller.getBoundingClientRect();
        const v = autoScrollSpeed(pointer.current.y, r.top, r.bottom);
        if (v) {
          scroller.scrollTop += v;
          const t = find(pointer.current.x, pointer.current.y);
          targetRef.current = t;
          setTarget(t);
        }
      }
      raf = requestAnimationFrame(tick);
    };
    raf = requestAnimationFrame(tick);
    return () => cancelAnimationFrame(raf);
  }, [active, find]);

  const end = useCallback((commit: boolean) => {
    const d = drag.current;
    const t = targetRef.current;
    drag.current = null;
    targetRef.current = null;
    setActive(null);
    setCard(null);
    setTarget(null);
    document.body.style.userSelect = "";
    if (!commit || !d || !d.lifted || !t) return;
    const s = d.source;
    if (s.kind === "task") {
      if (t.kind === "project") return void (t.name !== s.task.project && onDropRef.current({ kind: "project", source: s, project: t.name }));
      if (t.kind === "day") return void (t.date !== s.task.due && onDropRef.current({ kind: "day", source: s, date: t.date }));
      if (t.kind === "list" && t.list === "today") {
        const next = t.drop.kind === "between" ? t.rows[t.drop.index] : undefined;
        return void onDropRef.current({ kind: "today", source: s, beforeKey: next && next.kind === "task" ? next.key : null });
      }
      if (t.kind === "list") {
        const placement = placementOf(t.rows, t.drop, d.key!);
        if (placement) onDropRef.current({ kind: "place", source: s, placement });
      }
      return;
    }
    if (t.kind !== "order") return;
    const moving = s.kind === "section" ? s.name : s.name;
    const without = t.names.filter((n) => n !== moving);
    const insertAt = t.names.slice(0, t.index).filter((n) => n !== moving).length;
    without.splice(insertAt, 0, moving);
    if (without.join("\u001f") === t.names.join("\u001f")) return;
    if (s.kind === "section") onDropRef.current({ kind: "sections", project: s.project, names: without });
    else onDropRef.current({ kind: "projects", names: without });
  }, []);

  useEffect(() => {
    const move = (e: PointerEvent) => {
      const d = drag.current;
      if (!d) return;
      pointer.current = { x: e.clientX, y: e.clientY };
      if (!d.lifted) {
        if (Math.hypot(e.clientX - d.sx, e.clientY - d.sy) < LIFT) return;
        d.lifted = true;
        setActive(d.source);
        document.body.style.userSelect = "none";
      }
      setCard({ node: d.node, x: e.clientX, y: e.clientY, dx: d.sx - d.rect.left, dy: d.sy - d.rect.top, w: d.rect.width });
      const t = find(e.clientX, e.clientY);
      targetRef.current = t;
      setTarget(t);
    };
    const up = () => drag.current && end(true);
    const key = (e: KeyboardEvent) => {
      if (e.key === "Escape" && drag.current) {
        e.preventDefault();
        e.stopPropagation();
        end(false);
      }
    };
    window.addEventListener("pointermove", move);
    window.addEventListener("pointerup", up);
    window.addEventListener("keydown", key, true);
    return () => {
      window.removeEventListener("pointermove", move);
      window.removeEventListener("pointerup", up);
      window.removeEventListener("keydown", key, true);
    };
  }, [find, end]);

  const start = useCallback((e: React.PointerEvent, source: DragSource, node: React.ReactNode) => {
    if (e.button !== 0) return;
    e.preventDefault();
    const row = (e.currentTarget as HTMLElement).closest<HTMLElement>("[data-row], [data-drop-section], [data-project-item]") ?? (e.currentTarget as HTMLElement);
    drag.current = { source, sx: e.clientX, sy: e.clientY, lifted: false, node, rect: row.getBoundingClientRect(), key: source.kind === "task" ? `${source.task.project}/${source.task.no}` : undefined };
  }, []);

  const line = (y: number, x: number, w: number) => (
    <div style={{ position: "fixed", left: x - 4, top: y - 1, width: w, height: 2, background: "var(--color-accent)", pointerEvents: "none", zIndex: 81 }}>
      <span style={{ position: "absolute", left: 0, top: -3, width: 8, height: 8, boxSizing: "border-box", borderRadius: 4, border: "2px solid var(--color-accent)", background: "var(--color-bg)" }} />
    </div>
  );
  const ring = (r: { left: number; top: number; width: number; height: number }, fill: boolean) => (
    <div style={{ position: "fixed", left: r.left, top: r.top, width: r.width, height: r.height, borderRadius: 6, pointerEvents: "none", zIndex: 79, boxShadow: fill ? undefined : "inset 0 0 0 1px var(--color-accent)", background: fill ? "var(--color-accent-soft)" : undefined, mixBlendMode: fill ? "multiply" : undefined }} />
  );

  let indicator: React.ReactNode = null;
  if (target?.kind === "list" && target.drop.kind === "between") {
    const lr = document.querySelector(`[data-drop-list="${target.list}"]`)?.getBoundingClientRect();
    indicator = line(target.drop.y, target.drop.x, (lr?.right ?? target.drop.x + 600) - target.drop.x);
  } else if (target?.kind === "list" && target.drop.kind === "onto") {
    const el = document.querySelector<HTMLElement>(`[data-row][data-key="${CSS.escape(target.drop.key)}"]`);
    if (el) indicator = ring(el.getBoundingClientRect(), false);
  } else if (target?.kind === "project" || target?.kind === "day") {
    indicator = ring(target.rect, true);
  } else if (target?.kind === "order") {
    indicator = line(target.y, target.x + 4, target.w - 8);
  }

  return (
    <DragCtx.Provider value={{ start, active }}>
      {children}
      {active &&
        createPortal(
          <>
            {indicator}
            {card && (
              <div style={{ position: "fixed", left: card.x - card.dx + 6, top: card.y - card.dy, width: card.w, pointerEvents: "none", zIndex: 80, background: "var(--color-bg)", borderRadius: 6, boxShadow: "var(--shadow-popover)" }}>
                {card.node}
              </div>
            )}
          </>,
          document.body,
        )}
    </DragCtx.Provider>
  );
}
```

Notes for the implementer:
- `elementFromPoint` returns the topmost element. The card and indicators have `pointerEvents: "none"`, so they never hide what is under the pointer.
- For the Today list, `dragged.height = 2` disables "onto" (Today has no subtasks) and keeps the depth at 0.
